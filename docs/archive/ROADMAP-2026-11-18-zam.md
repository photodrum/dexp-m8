4. ✅ **B37: «Контраст» вместо «Тёплого света» — закрыто 2026-11-18 (Sonnet), проверено на книге
   в 0.3.0.** Решение человека:
   ползунок «Контраст» на месте «Тёплого света» (16 делений, `sys.gray.gammalevel`), тумблер
   «Усиленный контраст» убран. Подпись — проценты, как в шторке B5 (`round(деление · 100 / 15)`);
   пустое свойство системы заменяется `Prefs.gammaLevel` (прошивка `sys.*` не задаёт и сбрасывает
   при загрузке). `Prefs.warm`/`Prefs.contrast` удалены, проба `Sys.probeGamma` снята.
   В коде: `SetScreenScreen`, `SettingsKit.sliderContrast`, `Sys.setGamma`/`gammaIndex`.
   Проверено на книге 2026-11-18: касание 33 % → 73 %, панель не «гаснет», значение переживает
   перезапуск процесса.
18. ✅ **Гарнитура B4 не менялась у книг со своим шрифтом — закрыто 2026-11-16 (Opus).**
    Было: EPUB со своим `@font-face` не реагировал на B4 (1451 стр. при всех гарнитурах).
    Причина: имена из `font-family` книги пробуются раньше предпочтения пользователя, а шаг
    «предпочтение» (`_preferred_family`) в движке не заполнялся никогда. Сделано:
    `crengine.font.family.faces` (имена книги отбрасываются, все восемь generic-семейств →
    выбранная гарнитура) + `fontMan->SetPrimaryFont` в `apply_typography()` и до `LoadDocument`.
    Встроенные шрифты книги не отключены — синтез и фолбэк целы. Проверено на книге:
    база 5372 / гротеск 3647 / моно 4514, снимки разные. Подробности —
    `docs/archive/DEVLOG-2026-11-16-z18.md`, запись — `docs/DEVLOG.md` (верхняя).
19. ✅ **Падение в нативе на кегле 8–12 — закрыто 2026-11-18 (Opus).** `SIGBUS / BUS_ADRALN`
    в `LVFontGlyphCacheItem::newItem`: `alignas(16)` на `bmp` делал объект 16-байтно
    выровненным, clang на armv7 обнулял поля NEON-записью по 16 байт по адресу из `malloc`,
    а bionic даёт 8 → падение. Правка — `posix_memalign` (`allocItem`), живёт патчем
    `tools/patches/crengine-19-glyph-align.patch` (накладывает `cre.cmake`). Проверено на
    книге: кегли 8…13, 20, 32, 44, 61, 72 — 0 падений из 3; `SIZE_MIN` остался 8.
    ASan дефект не ловил (выровненный аллокатор). Подробности —
    `docs/archive/DEVLOG-2026-11-18-z19.md`.
20. ✅ **Зона шторки B5 перекрывает меню B50 в читалке — закрыто 2026-11-17 (Sonnet).**
    При выделении у верха страницы панель B50 встаёт в зону шторки (y < 513, x 468…936), и
    отпускание по «Заметке» или «Словарю» открывало шторку вместо листа. Сделано: `Screen.shadeAllowed`
    — экран может уступить свою зону элементу; `ReaderScreen` уступает габарит панели
    (`SelectionBar.contains`, 44…1365 × y0…y0+202), остальная зона и удержание — как были.
    Проверено на книге: «Словарь» и «Заметка» открываются, шторка без выделения и выше панели
    открывается по-прежнему. Подробности — `docs/archive/DEVLOG-2026-11-18-starye.md`.

21. ✅ **B43: кнопка «Автор» с QR-кодом на Бусти и имя автора в строке версии — закрыто 2026-11-18
    (Sonnet), проверено на книге.** Решение человека: нижняя тёмная кнопка B43 — «Автор»
    (иконка чашки `cup`), касание открывает новый экран `SetAuthorScreen` (`SCR_SET_AUTHOR`):
    QR-код `https://boosty.to/photodrum` (матрица 29×29 в `ui/AuthorQr.kt`, генерируется
    `tools/qr_matrix.py`, рисуется `ink.rect` — библиотек QR в проекте нет), пояснение
    «приложение бесплатное, автора можно угостить чашкой кофе» и адрес текстом. Строка версии —
    «Оболочка 0.3.0 · сборка 3, автор Денис Лампусов» (770 px при доступных 1016).
    Проверка обновлений с B43 убрана: её делает B76 сам при открытии, дверь — строка «Обновления».
    Своего борда в макете у экрана нет — попросить у дизайна (см. `docs/DESIGN_QUESTIONS.md`).
    Проверено на книге 2026-11-18: «Автор» открывается, «Понятно» возвращает на B43; матрица
    сверена с `segno` — совпадает посимвольно, то есть код ведёт на Бусти.


20. ✅ **Release-подпись — закрыто 2026-11-18 (Sonnet).** Свой ключ `~/.dexp-m8-keys/release.jks`
    (alias `dexp-m8`, SHA-256 `9E:DF:F2:D1…17:FC`, до 2054), `signingConfigs` в `app/build.gradle.kts`
    читает `release.properties` из того же каталога; **один ключ на debug и release** — иначе переход
    на свою подпись стирал базу и настройки. `versionCode 2` / `versionName 0.2.0`; release теперь
    подписан и содержит три `.so` (4,4 МиБ, раньше в `BUILD.md` значилось 145 КБ — то была сборка без натива).
    `tools/build.sh` берёт тот же ключ. Проверено на книге: `apksigner verify` — подпись совпадает
    у debug и release; книга (админ снят, данные сняты `run-as`) → 532 книги, место чтения «Ловец душ»
    115/218 (52%), настройки (`text_size 33`, `gamma_level 8`); release поверх debug и обратно — без
    потери данных, книга открывается (`b3: open ok`, позиция «есть»). Подробности и рецепт —
    `docs/BUILD.md` («Подпись APK», «Смена подписи без потери данных»), `docs/archive/DEVLOG-2026-11-18-starye.md`.
