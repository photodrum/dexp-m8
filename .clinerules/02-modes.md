# Режимы Plan / Act и модели

Plan — claude-opus-5.5 (High), Act — claude-sonnet-5.5 (Medium). Модель переключает только человек;
если задача не для текущей модели — остановиться и сказать, что переключить.

## Plan

- Предложить план маленькими шагами: файлы, что меняется, как проверить на книге. Выполнение — после «делай» и переключения в Act.
- Если выполнение входит в список «Act на Opus» — предупредить: «Для выполнения поставь Opus на вкладке Act».

## Act на Sonnet

Берёт: экраны оболочки по снимку макета, библиотека, сканер, база, полки, поиск, настройки,
приложения, OPDS, плеер, первый запуск, правки по замечаниям, тесты, документы и DEVLOG.

Не берёт — это задачи для Opus:

- проба и сборка движков R0, NDK, JNI, `ReaderEngine`;
- E-Ink-слой и драйвер Rockchip;
- системные права: яркость, сон, Wi-Fi, device admin (B5);
- архитектура: `EinkActivity`, `Screen`, `Ink`, `D`, правила `docs/ARCHITECTURE.md`;
- ошибка, не исправленная за 2 захода (сначала записать в DEVLOG, что пробовал и получил).

В этих случаях остановиться, ничего не ломая, и ответить:

> СТОП. Поставь claude-opus-5.5 на вкладке Act (Cline → API Configuration → Act Mode → Model ID)
> и напиши «продолжай». Причина: <почему>. С чего продолжить: <файл / запись DEVLOG>.

## Act на Opus

- Делать трудную часть; решения и грабли — подробно в DEVLOG, по ним дальше работает Sonnet.
- Когда осталась рутина — записать план в «СЛЕДУЮЩИЙ ШАГ» `docs/CONTEXT.md` и ответить:
  «СТОП. Сложное сделано. Верни claude-sonnet-5.5 на вкладке Act».

## Haiku (вручную)

Для документов, опечаток и разбора логов. Код не писать (кроме одной строки по точному указанию);
для кода ответить «СТОП. Верни claude-sonnet-5.5 на вкладке Act».

## Экономия токенов

- Одна задача — один чат; после шага предложить новый.
- Снимок макета — только нужного экрана.
- MCP (penpot, gitlab, trilium) добавляют десятки тысяч токенов на запрос — если не нужен, напомнить выключить.
