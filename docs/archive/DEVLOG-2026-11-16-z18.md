# DEVLOG — замечание 18: гарнитура B4 и шрифт книги (2026-11-16, Opus)

## Что было сломано

У EPUB со встроенным шрифтом гарнитура B4 не действовала вовсе: «Вспомнить всё.epub»
(`body { font-family: LiberationSerif_FB2BookID }` + `@font-face`) при кегле 72 давала
**1451 стр. при всех трёх гарнитурах**, снимок не менялся (найдено 2026-11-15).

## Где именно терялся выбор пользователя (по коду движка)

`LVFontSelector::select` (`third_party/crengine/crengine/src/lvfntman.cpp:6704`) выбирает
шрифт в таком порядке:

1. каждое имя из `font-family` книги, если семейство зарегистрировано (`findFamily`);
2. `preferred_family` — предпочтение пользователя;
3. любое семейство нужного generic-типа;
4. любое зарегистрированное.

`setDefaultFontFace` (`lvdocview.cpp:3907`) пишет только в `m_defaultFontFace` — это шрифт
для «своего» текста, шаг 1 его перебивает. А шаг 2 был **мёртв**: `_preferred_family`
заполняется только из `SetPrimaryFont` / `SetAsPreferredFontWithBias`, и последний в движке
**не вызывается ни разу** (проверено `grep` по всему `third_party/crengine`).

## Что сделано

- `face_family_faces()` (`app/src/main/cpp/engines/cre_session.cpp`) — строка для
  `crengine.font.family.faces` (`PROP_FONT_FAMILY_FACES` → `setFontFamilyFonts`,
  `lvtinydom.h:2888`): `[0]` непусто = «имена из книги отбрасывать», `[1]…[8]` — имена для
  восьми `css_font_family_t` (`serif, sans-serif, cursive, fantasy, monospace, math, emoji,
  fangsong`). Все восемь — выбранная гарнитура: у читалки она одна, и `font-family: monospace`
  из стилей книги тоже должен слушаться B4. В `lvstsheet.cpp:4349` generic-имя заменяется,
  а имя книги левее — вычёркивается.
- `apply_preferred_face()` — `fontMan->SetPrimaryFont(face)`, то есть шаг 2. Без него шаг 2
  не работает (см. выше), даже с подменой семейств: у книги без generic-имени подменять нечего.
- Оба вызова — в `apply_typography()` (смена настроек на лету) **и** в `dexp_reader_open`
  до `LoadDocument`: `font-family` разбирается при загрузке, позже стили узлов уже не
  перепишутся без полного `forceReinitStyles` (лишняя перевёрстка на каждой книге).
- Встроенные шрифты книги **не отключаются**: `crengine.doc.embedded.fonts.enabled` не
  трогаем, поэтому синтез начертаний и фолбэк для недостающих символов работают как раньше.

## Грабли

- Задачи `compileDebugNative` в проекте нет (это имя придумал я) — только `assembleDebug`.
- После `touch` исходника без пересборки `.so` в `merged_native_libs` остаётся старым, хотя
  Gradle пишет `UP-TO-DATE`: сверять `stat -c '%y'` у `.o`, `obj/libdexp_cre.so` и APK.
- `adb pull` в каталог с русским именем — путь в кавычках целиком, иначе `adb` ругается.
- `tools/typecheck.sh` без `JAVA_HOME` в PATH падает `java: command not found` и пишет
  «классов собрано: 0» — это не ошибка кода.
