## Цель и правила работы (прежний текст из CONTEXT.md)

> Актуальный сокращённый вариант — в `docs/CONTEXT.md`; порядок старта для Cline — `.clinerules/`.

### Цель

Своя оболочка для электронной книги DEXP M8 Prudentia: полная замена родного интерфейса —
лаунчер, библиотека, читалка, плеер. Не перепрошивка, а Android-приложения, которые ставятся
поверх родных. Дизайн рисуется в Penpot и переносится в код; ассистент пишет код и скрипты,
пользователь собирает и тестирует на книге.

Лицензия проекта — **AGPL-3.0**, исходники открыты (GitLab, GitHub). Читалка — свой UI
+ CREngine / MuPDF / DjVuLibre, делается после оболочки (`docs/READER_SPEC.md`).

### Правила работы в чате

- Ассистент — ведущий UI/UX-архитектор и Senior Android-разработчик (Embedded / Low-End).
  Язык — **русский**.
- **Один маленький шаг за раз**, максимально подробно: какие кнопки нажать, что вписать,
  чего ожидать. Пользователь опыта Android-разработки не имеет.
- Если действие должен сделать человек — расписывать по шагам и **ждать подтверждения
  после каждого шага**. Не сваливать пять действий в один абзац.
- При каждом коммите обновлять этот файл и `DEVLOG.md`.
- Замечания пользователя сначала записывать, приступать после слова «делай».
- Cline читает правила из `.clinerules/` автоматически (рабочая папка VS Code — сам репозиторий
  `dexp-m8`): порядок старта, режимы Plan = Opus / Act = Sonnet, когда просить сменить модель.
