## 2026-11-14 — R2.1: сеанс DjVu за `Engine` (Opus)

- **Код:** `engines/djvu_session.cpp` — документ держится между вызовами, контекст и формат GREY8 — раз на процесс,
  кэш 8 МБ; `engines/djvu_jni.cpp` → `reader/DjvuEngine.kt`; `Engine` выбирает движок в `open` по расширению
  (`djvu`, `djv`), остальные методы ветвятся по `Engine.djvu`, `setFont` для DjVu — OK без вызова. `ReaderScreen` не менялся.
- **Позиция** — `djvu:<страница>` (разбор понимает и `djvu:<стр>:<смещение>` на будущий масштаб B31); чужая позиция
  (xpointer) → `EPOS`, книга открывается с начала. Оглавление — из `ddjvu_document_get_outline` (`#12` / `#файл`).
- **Ошибки кодом:** файл не открылся / 0 страниц → `EOPEN` (B45), битая страница → `EPAGE` (B59 в R2.3), документ открыт.
- `utf8ToJString` вынесен из `reader_jni.cpp` в общий `engines/jni_utf8.h`; правило R8 `-keep DjvuEngine`.
- **Сборка:** `assembleDebug` OK, APK 5 524 272 б, `libdexp_djvu.so` 570 400 б (14 JNI-символов `DjvuEngine`).
  **На книге не проверено** — книга не была подключена к adb.

## 2026-11-13 — Приёмка R1: FB2 и EPUB на книге (Sonnet)

- **FB2** (1135 стр., оглавление 164 пункта): листание вперёд и назад, текст без артефактов; страница строится
  40–48 мс, открытие из кэша 248–422 мс. Место чтения: выход «назад» и повторное открытие — та же страница (14);
  после `am force-stop` — страница 15, как при выходе (`save page=15/1135`, затем `pos=есть -> 14` с нуля).
- **EPUB** «Вспомнить всё» (198 стр., оглавление 41 пункт): листание вперёд и назад в порядке; страница 57–92 мс;
  первое открытие 1610 мс (разметка), повторное 85 мс. Выход и повторное открытие — та же страница;
  после `force-stop` открылась страница 17 из 198, на которой закрыли.
- **Память:** PSS 31,5–42,8 МБ (TOTAL по `dumpsys meminfo`; пик — сразу после листания FB2 на 1135 стр.).
- **Итог:** критерии приёмки R1 выполнены на FB2 и EPUB, R1 закрыт. Замеры — с книги `6IVJ8C68AP`, APK от 20:38.
  Не проверено: смена кегля (R3), DjVu (R2).

## 2026-11-14 — R2.2: DjVu на книге (Opus)

- **r0-test.djvu** (1 стр.): открытие 28 мс, страница 621 мс. **r0-multi.djvu** (40 стр., 14,5 МБ, цветной скан):
  открытие 6 мс, страница 1430–1600 мс (как в R0 — ≈1,5 с); с предзагрузкой листание вперёд без ожидания,
  если между нажатиями > 1,6 с. Назад — тоже 1,4–1,6 с (предзагрузка идёт по направлению). Картинка верная, 16 уровней.

- **Память:** PSS 48,0 МБ (Native Heap 31,4 МБ) после 10 листаний цветного скана — в пределах 60 МБ.
- **Битые файлы** (во временной папке, удалены): обрезанный до 300 КБ — `open ok`, стр. 0 → `EPAGE` (-3), диалог
  B45 «страница не загрузилась» (вместо B59 — экрана ещё нет); мусор и пустой файл → `EOPEN` (-2), B45. Падений 0.
- **Итог:** приёмка R2 по движку выполнена. Остаётся R2.3 (B59, B31). Оглавлений в тестовых файлах нет — `toc()` на реальном DjVu не проверен.
