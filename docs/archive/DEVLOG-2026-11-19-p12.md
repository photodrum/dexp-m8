## Решения

1. **Книга = папка.** У MP3-книги главы — отдельные файлы, склеить их можно только по папке.
   Одиночный `.m4b` — тоже «папка», ключ — путь файла: иначе два `.m4b` в одной папке
   стали бы одной книгой.
2. **Одно место на книгу, в мс.** Прогресс книги не разваливается при переходе между файлами;
   позиция файла = `позиция книги − смещение файла`.
3. **Один `MediaPlayer`.** Не `ExoPlayer` (AndroidX, запрещён правилами) и не свой конвейер.
   Смена `dataset` при переходе файла — дешевле, чем пул проигрывателей.
4. **Тик 15 с.** На E-Ink перерисовка — мерцание, поэтому чаще не нужно; он же пишет место
   в базу (п. 12: «прогресс раз в 10–30 с») и проверяет таймер сна.
5. **«Пропускать паузы».** Отсекаем только хвост файла (2 с) при переходе к следующей главе.
   Вырезание тишины по амплитуде требует своего конвейера MediaExtractor+MediaCodec —
   отдельная задача, в макете это одна строка, а не требование точности.
6. **Главы.** У M4B — встроенные `chpl`, у MP3 — `CHAP`; если разметки нет — одна глава
   на файл (имя файла без расширения). Так B34 всегда непустой.
7. **Обложки** — заглушка из начала названия, как в макете B33: картинка из ID3 весит
   на E-Ink лишнюю память, а хранить её негде (база обложек к аудио не относится).

## Правки по снимкам с книги

- B7: шкала рисовалась не полностью и тонкой толщиной — теперь 27 тонких штрихов G7 (1.5)
  по снимку и 5 жирных G1 слева по проценту книги; иконки параметров ставятся по макету
  (+44.8 — иконка 47.5×49.5, подпись +112.5), а не по центру кнопки.
- B35: «−» рисовался размером 30.9×2.2 (у иконки `minus` такого нет) — теперь 45.7×47.6;
  «+» белой иконкой на выпуклой клавише был невидим — теперь тёмные штрихи 2.5 G4.
- B33: в строке списка убрана надпись на миниатюре (в макете текст только на большой
  обложке карточки); карточка «сейчас слушаете» показывается только у начатой книги.
- B34: иконка play в текущей главе не рисовалась — был размер `play@30x33`, такой спеки нет;
  теперь базовая `play` 35.8×42.8 в круге 115×120.

## Что ещё не проверено

- Настоящая запись голоса (тестовые файлы — тишина): слышимость, паузы, «Пропускать паузы»
  на живой речи, скорость на слух.
- `.m4b` на книге: проверен только хостовым тестом парсера `chpl`.
- Таймер «до конца главы» (сегмент B35) и 15 мин — не дожидались срабатывания.

## Грабли окружения

- Терминал VS Code теряет вывод долгих команд и «приостанавливает» фоновые (`Stopped`);
  сборка через `setsid nohup bash /tmp/x.sh &` + лог в `/tmp/*.log` работает надёжно.
- `kotlinc` для хостового теста без Android требует явных импортов из `ru.ogrpfsense.dexpm8.core`,
  а класс main называется по имени файла: `tools/audio_chapters_test.kt` → `Audio_chapters_testKt`.
- На книге нет `ffmpeg` и mp3 в системе; тестовое аудио собрано python-скриптом (кадры тишины).
