# B19 — заставка сна (2026-11-18)

Пункт 13, заставка сна. Подробности к записи `docs/DEVLOG.md` от 2026-11-18.

## Что показала разведка на книге

- `screensaver_components` = `com.google.android.deskclock/com.android.deskclock.Screensaver`,
  но пакета `com.android.deskclock` на прошивке нет; `dumpsys dream` — `Can't find service: dream`.
  Системная заставка (DreamService) на этой книге не работает вовсе.
- `screensaver_activate_on_sleep` = 0, `lockscreen.disabled` = 1.
- `dumpsys window`: `mDreamingLockscreen=false`, keyguard не мешает.

Отсюда решение: своя заставка — обычный `View` поверх текущего экрана, а не DreamService.

## Почему кадр рисуется до гашения

На E-Ink подсветка и изображение независимы: после `lockNow`/тайм-аута панель показывает
последний отправленный кадр. Перерисовать что-либо на выключенном экране нельзя, поэтому
заставка показывается **за 20 с до** системного гашения (`SLEEP_LEAD_MS`), пока панель горит.
Своего гашения нет — его делает система.

Следствия:

- device admin не нужен для заставки по тайм-ауту (нужен только для кнопки «Сон» на B5);
- при коротком сне запас урезается до четверти тайм-аута: `min(20 с, timeout/4)`;
- «Никогда» (`Int.MAX_VALUE`) — заставки нет, планировать нечего.

## Код

- `ui/SleepScreen.kt` — B19: строка сна, гнездо `inset` + обложка G14 + корешок G3, название
  на обложке Literata 84/600 с переносом по последнему влезающему пробелу, название/автор/прогресс
  по центру, дорожка `inset` + G3, подсказка `inset` + `battery` + 36/600.
  Данные: `LibraryDb.lastOpened()` и липкий `ACTION_BATTERY_CHANGED`.
- `EinkActivity`: `planSleep` (по `sys.sleepTimeout()`), `curtain`, `sleepShown`, `wakeUp`,
  `rescheduleSleep`, `onUserInteraction`. `changeTo` снимает заставку, `onPause` снимает план,
  `onResume` зовёт `wakeUp` (возврат из фона = пробуждение).
- «Назад» и любые клавиши при показанной заставке только будят: иначе листание вслепую
  переворачивало страницу под заставкой.
- «Сон» на B5: сначала `curtain()`, через `LOCK_MS` (700 мс) — `sys.lockNow()`.
- `SetSleepScreen`: смена «Засыпать через» зовёт `act.rescheduleSleep()`.
