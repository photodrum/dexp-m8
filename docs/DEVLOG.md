# Журнал разработки

## 2026-11-07 — этап 1: каркас оболочки и C-ядро

**Снятие дизайна с Penpot.** Прочитана страница v5 файла «UI»: 46 бордов 1404×1872.
Проверена палитра по всем бордам — фактически используются ровно 16 градаций с шагом 17,
посторонних цветов нет. Снята геометрия B1 и B2 до пикселя, выгружена геометрия 63 иконок
(каждая — два слоя: блик `#FFFFFF` `+3,+3` под контуром).

**Отказ от dp в пользу дизайн-px.** В ТЗ была формула «1 pt ≈ 4.2 px», по которой ширина
экрана выходила `334 dp` вместо реальных `702 dp` — вся вёрстка стала бы вдвое мельче.
4.17 = `300 ppi / 72` (типографский пункт), а dp считается от 160. Решение: рисовать
в пикселях макета, масштабируя `Canvas` один раз через `D.u = screenW / 1404f`.

**UI без единой зависимости.** Ни AndroidX, ни Material, ни Compose, ни RecyclerView.
`EinkActivity` — единственная Activity, экраны — `View` в стеке, переходы без анимаций,
свой статус-бар, `immersive`. Экономия PSS на PX30 с 1 ГБ — главный аргумент.

**Иконки числовой геометрией.** Вместо SVG в assets и Bitmap на все плотности — примитивы
в `IconSpecs.kt` (rectangle / ellipse / path), парсятся один раз, `Path` кэшируются.
Ноль байт в APK, всегда резкие, толщина штриха не плывёт.

**C-ядро разбора FB2.** Свой потоковый токенизатор вместо libxml2/expat: один проход,
стек тегов, текстовая арена на документ. Книга 5 МБ даёт ~2 МБ блоков, а не 50 МБ DOM.

### Найденные баги (исправлены)

1. `buf_normalize` в `book.c`: при нераспознанной сущности не сдвигался индекс — бесконечный цикл.
2. `Tokens.kt`: `R` не виден из пакета `ui` без явного `import ru.ogrpfsense.dexpm8.R`.
3. `Ink.paragraph`: `lastSpace` присваивался после проверки → мёртвая ветка переноса.
4. **Дефисы в именах ресурсов запрещены.** `res/font/manrope-700.ttf` проходит `aapt2`
   напрямую, но Gradle падает: только `a-z0-9_`. Переименовано в `manrope_700.ttf`.
5. **R8 удалял JNI-класс.** `-keepclasseswithmembernames ... native <methods>` разрешает
   shrinking: пока `NativeBook` никто не вызывает из Kotlin, он вылетает из APK и JNI
   падает на `UnsatisfiedLinkError`. Нужен `-keep class ... { *; }`. Проверено: было
   0 упоминаний в release-dex, стало 21.
6. `aapt2` требует `package` в `<manifest>`, а AGP 8 его вырезает (берёт из `namespace`).
7. `d8` — шелл-обёртка, ищет `java` в `PATH`.

### Окружение сборки

Поставлено без sudo в `~/.local`: JDK 17.0.21 (Temurin), Android SDK (platforms 27 и 34,
build-tools 34.0.0, NDK r26d, CMake 3.22.1, platform-tools), Kotlin 1.9.24, Gradle 8.7.
Gradle скачал CMake сам при первой сборке.

### Сборка

- `assembleDebug` — 965 КБ, внутри `lib/arm64-v8a/libdexp_core.so` (12 КБ) и `x86_64`.
- `assembleRelease` (R8) — 145 КБ, JNI-класс сохранён.
- `tools/build.sh` — быстрый путь без Gradle (~10 сек), но без `.so` и CMake.
- C-ядро на хосте: `gcc` + ASan/UBSan, 9 из 9 проверок зелёные.

## 2026-11-07 — репозиторий и доступы

**GitLab.** Проект `denisle/dexp-m8` (id 87). Первый push упёрся в права: токен
`mcp-agent` — fine-grained, выдан только на `MCP tool: Execute`, поэтому
`git push` отвечал `403 [Code: Push]`. Создан отдельный legacy PAT у аккаунта `denisle`
с `write_repository`, хранится в `~/.config/dexp-m8/git-push-token` (600),
подставляется через `tools/git-askpass.sh`.

**SSH не заработал.** `git.ogrpfsense.ru:22` отвечает `OpenSSH_9.2p1 Debian-2+deb12u10` —
это NPM-хост, а не GitLab VM (там Debian 13). Ключ предъявляется, но сервер его не знает.
Порты `2222` и `443` для SSH закрыты. Остались на HTTPS.

**Git identity.** Первый коммит сделан от `mcp-agent` (я ставил его до того, как ты
уточнил аккаунт), второй — от `denisle`. В истории это видно, при желании перепишем.

**Документация.** Заведена папка `docs/` в формате проекта `sandstorm-ai`.
