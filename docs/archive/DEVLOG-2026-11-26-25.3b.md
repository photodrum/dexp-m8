# 25.3б — экраны игры по сети B85–B87б (2026-11-26, Sonnet)

План — `docs/archive/DEVLOG-2026-11-26-25.3.md`, раздел «25.3б». Числа — `design/v5/B85…B87б.json`
(`python3 tools/design_flat.py B85`).

## Файлы

- `ui/ChessNetScreen.kt` — B85 (сегменты `Fics.CONTROLS`, «Искать соперника» → `ChessNet.seek`),
  поверх: B85а при `CONNECTING`/`SEEKING`, B87 при `OFFLINE`. PLAYING → `go(SCR_CHESS_ONLINE)`.
- `ui/ChessOnlineScreen.kt` — B86: доска `ChessBoard` по `ChessNet.net.game`, свои выбор и ход,
  превращение (`ChessSheets`), «Сдаться?» (`ChessDialogs`), диалог из `layer()`.
- `ui/ChessNetDialogs.kt` — B85а, B87, B87а, B87б; кнопки `LEFT` / `RIGHT`.
- `ui/ChessMenuScreen.kt` — строки «По сети» и «Вернуться к партии», зона касаний по номеру строки.
- `ui/ChessMovesScreen.kt` — партия по сети при `ChessNet.movesOnline`.
- `ui/ChessNet.kt` — только `movesOnline`; `EinkActivity` — `SCR_CHESS_NET` = 46, `SCR_CHESS_ONLINE` = 47.

## Решения

1. Диалог B86 — не поле экрана, а `layer()` из `ChessNet.state`: ENDED/OFFLINE сильнее ничьей
   соперника, она сильнее своих листов. Вернулись на экран (после B81) — слой тот же.
2. Секундные рамки: `invalidate(l, t, r, b)` (устарел с API 28, на 8.1 штатный; `@Suppress`).
   B85а — рамка счётчика 152,810 1100×130; B86 — рамка часов 1126…1368 × (плашка −14 … +100),
   и только если текст часов сменился (`lastTop`/`lastBottom`, их ставит и `render`). Пока открыт
   лист или диалог, часы не перерисовываются.
3. «Назад» (кнопка и системная) посреди партии открывает B84 «Сдаться?»; «Сдаться» шлёт
   `resign`, B83 появляется, когда сервер пришлёт конец партии. «Домой» партию не обрывает:
   `ChessNet` живёт в процессе, на B77 — «Вернуться к партии».
4. B87а: гостю доигрывания нет (`forfeits by disconnection` сразу), поэтому «Ждать» заменено
   «Новая партия», пояснение — «Сервер закончил партию сразу…» (вопрос дизайну —
   `DESIGN_QUESTIONS.md`).
5. B87 посреди партии: «Повторить» ведёт на B85 (вернуть партию нельзя), пояснение об этом.
6. Номер хода — из позиции (`fullmoveNumber`, сторона), не из индекса листа SAN: после
   пересборки из FEN (`NetGame.resyncs`) лист начинается посреди партии.
7. Контроль на B85 помнится только в процессе (`ChessNet.minutes/increment`), в `Prefs` не пишется.
8. Два экрана на один `onChange`: экран снимает свой обработчик только если он ещё его
   (`ChessNet.onChange === change`) — B86 включается раньше, чем отключается B85.
