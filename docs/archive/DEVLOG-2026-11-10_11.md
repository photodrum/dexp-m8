## 2026-11-11 — п. 4, шаг 4.6: запись настроек (Opus)

Сделано одним шагом по решению пользователя: системное + device admin + свои настройки.
Новые файлы: `core/Sys.kt` — общий слой для B37–B42 и будущей панели B5 (п. 8): яркость (ставит ручной режим и
`SCREEN_BRIGHTNESS` 0…255), `SCREEN_OFF_TIMEOUT` («Никогда» = `Int.MAX_VALUE`), `TIME_12_24` — всё через WRITE_SETTINGS;
Wi-Fi — `WifiManager.setWifiEnabled`, Bluetooth — `BluetoothAdapter.enable/disable` (обычные права, асинхронно);
`lockNow` — device admin; `clearCache` — внутренний и внешний кэш. `core/Prefs.kt` — SharedPreferences «shell»,
значения по умолчанию из макетов. `core/AdminReceiver.kt` + `res/xml/device_admin.xml` (одна политика — force-lock).
Манифест: WRITE_SETTINGS, ACCESS/CHANGE_WIFI_STATE, BLUETOOTH, BLUETOOTH_ADMIN, receiver админа.
`EinkActivity`: `sys`, `prefs`; `withWriteSettings(action)` — нет права → `ACTION_MANAGE_WRITE_SETTINGS`, после возврата
право проверяется заново и действие выполняется; `requestAdmin`, `sleepNow` (для B5); после обоих системных экранов —
белый кадр (`cleanOnFocus`). `SettingsKit`: `inRow`, `sliderHit` (касание дорожки, шаг 5 %; иконки по краям ±10),
`segmentHit`.
Экраны: B37 — яркость в систему, тёплый свет/режим/очистка/контраст в Prefs; B38 — тумблеры Wi-Fi и Bluetooth
(через 2,5 с одна сверка с системой), «Выключать Wi-Fi во сне» в Prefs; B39 — переносы, зоны, свайп в Prefs;
B40 — «Засыпать через» в систему, экономия и заряд на заставке в Prefs; B41 — 24-часовой формат в систему;
B42 — «Очистить» кэш, «Файлы загрузок» в Prefs.
**Не пишется (ограничение Android):** «Время по сети» (`auto_time`) и порог экономии — `Settings.Global` требует
WRITE_SECURE_SETTINGS (только системным). Значения из Prefs (тёплый свет, режим обновления, контраст, экономия, Wi-Fi
во сне) пока только хранятся — исполнять будут драйвер Rockchip/B5 (п. 8), читалка и B19/B20. Тёплый свет на этой книге
может не иметь системного ключа — проверить в п. 8. Строки со стрелкой (`next`) без своих экранов в макете не нажимаются.
Device admin в оболочке пока не вызывается (кнопки «Сон» нет до B5). Пока админ включён, оболочку не удалить без
его отключения; `adb install -r` не мешает.
`typecheck.sh`: 70 классов, ошибок 0; `assembleDebug` прошёл (предупреждения только об устаревших API — для API 27 они
актуальны). На книге не проверено (4.7).
