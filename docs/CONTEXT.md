## Цель

Своя оболочка для электронной книги DEXP M8 Prudentia: полная замена родного интерфейса —
лаунчер, библиотека, читалка, плеер. Не перепрошивка, а Android-приложения, которые ставятся
поверх родных. Дизайн рисуется в Penpot и переносится в код; ассистент пишет код и скрипты,
пользователь собирает и тестирует на книге.

## Архитектура (как сейчас устроено)

```
app/src/main/java/ru/ogrpfsense/dexpm8/
  ui/   EinkActivity  единственная Activity: стек экранов, immersive, без анимаций
        Screen        базовый View: layout/render/onUp, касания без скролла
        Ink           рисование: convex / convexDark / inset, текст, абзацы
        Tokens        палитра G0..G15, радиусы, кегли, кэш Typeface
        D             дизайн-пространство: u = width/1404, масштаб Canvas
        Icons         отрисовка иконок из числовой геометрии
        IconSpecs     геометрия 24 иконок, снятая с Penpot
        HomeScreen    B1 «Главный»
        LibraryScreen B2 «Библиотека» (список)
        SimpleScreen  заглушка раздела для проверки навигации
  core/ NativeBook    JNI-мост к C-ядру, грузится лениво
app/src/main/cpp/
  core/book.c,.h      потоковый разбор FB2
  jni_bridge.c        JNI
  test/               хостовые тесты (gcc + ASan), без NDK
```

**Ключевое решение — дизайн-px, а не dp.** Макет нарисован в пикселях панели (1404×1872),
поэтому все View рисуют в числах макета, а `Canvas` масштабируется один раз: `D.u = screenW / 1404f`.
На этой книге `u = 1.0` — отступ 41 из Penpot становится `41f` в коде.

**Почему не dp:** в ТЗ была формула «1 pt ≈ 4.2 px». Это типографский пункт (`300/72 = 4.17`),
а dp в Android считается от 160, не от 72. Правильно: `density = 300/160 ≈ 1.875 → 2.0`,
`1404 px / 2.0 = 702 dp`. По формуле 4.2 вышло бы `334 dp` — вёрстка вдвое мельче нужной.

## Ключевые факты: E-Ink

- Экран 7.8″ Carta, **1404×1872 px**, 300 ppi, 16 градаций, сенсор.
- Палитра — шаг 17; все 46 бордов Penpot используют только её (проверено):
  `G0 #000000`, `G1 #111111` текст, `G3 #333333` тёмная клавиша, `G4 #444444` вторичный
  текст и контур иконок, `G5 #555555` подписи, `G6 #666666` плейсхолдер,
  `G10 #AAAAAA` тень, `G11 #BBBBBB` обод/разделитель, `G12 #CCCCCC` дно,
  `G13 #DDDDDD` фон, `G14 #EEEEEE` поверхность, `G15 #FFFFFF` блик.
- Объём — ступенчатые слои без размытия (формулы сняты со слоёв макета):
  - выпуклая: тень `G10 +5,+10` → блик `G15 0,0` → поверхность `G14 +3,+3` (`W-5 × H-10`);
  - вдавленная: нижний блик `G15` → внутренняя тень `G10` (`W-3 × H-3`) → дно `G12 +3,+5`
    (`W-6 × H-8`);
  - тёмная клавиша: `G8` тень → `G6` блик → `G3` поверхность.
- Радиусы: плитка/панель/поле `51.1875`, главная кнопка `65.8125`, гнездо обложки
  `32.90625`, внутреннее `30.1640625`, обложка `10.96875`.
- Запрещено: анимации, переходы, градиенты, полупрозрачность, размытие, скролл.
- Диалоги — без затемнения фона: перекрытие поверхностью или текст `G10`.
- Тач-зоны ≥ 48 dp, при density 2.0 это ≥ 96 px макета. Текущие зоны проходят
  с запасом (кнопка «Назад» 107×112, плитки 641×332, кнопки страниц 122×127).

## Ключевые факты: Penpot

- Файл «UI», 7 страниц; рабочая **v5** — 46 бордов 1404×1872.
  Сетка: шаг по X 1564, ряды Y = 19864 / 22100 / 24300.
- Имена: `B1 · Главный экран · Пластик · 1404×1872` … `B46 · Нет разрешения · подсказка · Пластик`.
- Страница `v5 дизайн-система` пуста — токены живут прямо в слоях.
- `page.root.children.filter(s => s.type === 'board')` — только борды холста.
  `findShapes({type:'board'})` рекурсивен и даёт все вложенные (209 и т.п.) — **не путать**.
- У `path`-фигуры есть готовое свойство `d` (в координатах страницы) — нормализуем
  в систему иконки вычитанием её `x,y`.
- Иконка в макете — группа из двух слоёв: блик `#FFFFFF` со сдвигом `+3,+3` под контуром.
- `export_shape` для страницы отдаёт PNG 1×1 — бесполезно, экспортировать только борд по id.
- Геометрия эталона B1: поля 41; карточка `41,275 1321×741`; гнездо обложки `88,322 293×424`;

## Что сделано

- **Дизайн-система перенесена в код**: палитра, радиусы, кегли (28…150), формулы теней.
- **24 иконки** — числовой геометрией в `IconSpecs.kt`, не SVG и не Bitmap: ноль байт
  в APK, всегда резкие, толщина штриха не плывёт при масштабировании.
- **B1 «Главный»**: статус-бар (время / батарея / wifi), дата, приветствие, карточка
  «Сейчас читаю» с обложкой и прогрессом 45 %, тёмная кнопка, 4 плитки, статистика.
- **B2 «Библиотека»**: назад, заголовок, переключатель вид, поиск, сегментированная
  сортировка, список 6 книг с разделителями, постраничность.
- **Навигация**: стек экранов, `onBackPressed → pop()`, без анимаций, `immersive`.
- **C-ядро**: потоковый разбор FB2, стек тегов (вложенные `emphasis`/`strong`), текстовая
  арена на документ, блоки PARA/TITLE/SUBTITLE/EPIGRAPH/POEM/ANNOTATION/EMPTY, метаданные.
- **Сборка**: `assembleDebug` 965 КБ с `libdexp_core.so`; `assembleRelease` с R8 — 145 КБ.
- **CI**: `core:test` (gcc + ASan), `kotlin:typecheck`, `assemble:debug`.
