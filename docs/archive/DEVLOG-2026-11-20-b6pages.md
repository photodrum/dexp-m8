# 2026-11-20 — B6: страницы при > 12 приложениях проверены на книге

Подробности записи «B6: страницы при > 12 приложениях» из `docs/DEVLOG.md`.
Закрывает пункт «Ждут проверки на книге» из `docs/ROADMAP.md`.

## Условия

На книге было 7 приложений + синтетическая плитка «Файлы» = 8 плиток при `PER_PAGE = 12` —
пагинация не рисовалась (один сегмент). Поставили **пять тестовых APK** (`ru.dexpm8.test.app1…5`,
подпись `tools/debug.keystore`, ключ `dexp`): 12 приложений + «Файлы» = 13 плиток → 2 страницы.
Код не менялся — проверялся уже установленный APK `0.3.0`, коммит `main` без правок.

APK для проверки собираются без Gradle за ~10 с и **без сети**: `aapt2 link` (манифест с
`LAUNCHER`-активностью и подписью «Тест N») → `d8` → `zipalign` → `apksigner`. Скрипт —
`tools/test_apps.sh`, дальше `adb install -r -d`.

## Результаты

- **Страница 1.** «12 установлено · 0,1 ГБ», ровно 12 плиток в сетке 3×4, желоб внизу — два сегмента,
  первый тёмный. Порядок по алфавиту (`Collator` ru): Галерея, Музыка, Настройки, Словарь, Тест 1–5,
  Файлы, AlReaderX Pro, Chrome, ELauncher.
- **Листание.** Тап по правой половине желоба (y 1730…1840) → страница 2: одна плитка «ELauncher»,
  желоб со вторым тёмным сегментом. Повторный тап вправо остаётся на 2-й (`goPage` зажимает `0…pages-1`),
  тап влево возвращает на 1-ю с полным набором плиток.
- **«…» на 2-й странице.** Правый верхний угол плитки (`DOTS_HIT` 100×100) → лист B36 поверх
  затемнённого экрана: «ELauncher», «Версия 1.0.0 · 15 МБ · установлено 19 мая», пять строк,
  выбранная плитка нарисована вдавленной. Тап выше `SHEET_TOP` закрывает лист, страница та же.
- **Скрытие со 2-й страницы.** «Скрыть из списка» → «11 установлено · 0,1 ГБ · скрыто 1», экран
  вернулся на страницу 1 (12 → 11 плиток), желоб снова из одного сегмента. «Скрытые» (тап по
  подзаголовку) показал «1 скрыто · нажмите, чтобы вернуть»; тап по плитке вернул приложение,
  снова «12 установлено», две страницы.
- **Запуск с B6.** Тап по плитке «Тест 1» → системный экран тестового приложения; `KEYCODE_BACK`
  возвращает на B6 с той же страницей и без залипшей «нажатой» плитки (`onWindowFocusChanged`).
- **B36 у AlReaderX Pro.** Запрос разрешений на файлы открылся по тапу «…» — сам лист не открывали
  (см. ниже).

## Чистка и состояние книги

Пять тестовых пакетов сняты (`adb uninstall`), `pm list packages -3` снова только
`com.neverland.alreaderpro` и `ru.ogrpfsense.dexpm8`; launcher-активностей 8 (7 приложений +
оболочка). B6 после перезапуска — «7 установлено · 0,1 ГБ», одна страница, 7 плиток.
Яркость 102, `wifi_on` = 1, батарея `status 5`, уровень 100 — как до опыта.

## Грабля: `settings put` без `--user 0` не записался

`am force-stop` снял службу питания (известная грабля). `adb shell settings put secure
enabled_accessibility_services …` на этот раз прошёл **без ошибки, но значение не записалось**:
`settings list secure` оставался с пустым `enabled_accessibility_services` и `accessibility_enabled=0`.
Помогла явная ссылка на пользователя — `settings put --user 0 …` (то же делает
`cmd settings put --user 0 …`); после записи — `power: service connected` в трассе. Порядок в
`docs/BUILD.md`, «Служба „DEXP M8 — выключение“».

## Не проверено

- «Идёт поиск книг…» — нужен `pm clear` (сносит базу и `shell.xml`).
- «Удалить приложение» в B36 для `AlReaderX Pro` — системный диалог не открывали, чтобы не удалить
  его случайно (и запрос разрешений на файлы перекрыл лист в этом заходе).
