### Замечания по итогам проверки на книге 2026-11-11 (записаны; правки — после слова «делай»)

Установлен APK `53de4d4`; PSS 21 784 КБ ≈ 21,3 МБ (было 19,8). B1 из базы («518 книг», «Сейчас читаю»), вход в библиотеку без диалога права, ошибок в logcat нет.

1. **Белый кадр после диалога права не срабатывает на холодном старте** (3.9г): в трассе нет `eink: clean after dialog`, остался след «РАЗРЕШИТЬ». Причина (гипотеза): `requestStorage()` зовётся из `onCreate` до первого фокуса окна, `onWindowFocusChanged(false)` не приходит, `cleanOnFocus` не ставится. Правка — **Opus** (`EinkActivity`); увеличивать `CLEAN_MS` бесполезно. Трасса книги: `/sdcard/Android/data/ru.ogrpfsense.dexpm8/files/DexpM8-trace.txt`.
2. ✅ **B1, строка «Сегодня 42 мин…»** — убрана (2026-11-11), вернуть вместе с читалкой.
3. B1, обложка-заглушка: «Автор неизв…» обрезается. Мелочь.
4. **B37: на книге нет «Тёплого/холодного света»** — заменить ползунок «Тёплый свет» на **«Контраст»**. Решения (2026-11-11): у книги контраст — ползунок с делениями; тумблер «Усиленный контраст» в блоке «ОТОБРАЖЕНИЕ» **убрать**; остальное (место ползунка, подпись, число делений) — решает Cline по снимку книги. Нужно от пользователя: (а) ~~снять ключ контраста~~ **найден 2026-11-11:** системное свойство `sys.gray.gammalevel` (`getprop`), минимум деления = `0`, максимум = `80`; в `Settings.System/Global/Secure` изменений нет. Деления (замер 2026-11-11): 0, 6, 11, 16, 21, 26, 31, 36, 41, 46, 51, 56, 61, 66, 71, 80 — **16 делений**, шаг ≈5 (первый 6, последний 80, а не 76). Из `adb shell` `setprop sys.gray.gammalevel 40` срабатывает: контраст сразу меняется на экране, значение записывается. Не выяснено: может ли писать обычное приложение (`adb` работает от `shell`, у приложения права меньше; по SELinux Android 8.1 вероятно нет) — проверка только на книге, пробным кодом в `Sys`; (б) попросить чат дизайна новый `design/v5/B37.json` (ползунок с делениями вместо «Тёплого света», без тумблера контраста; подзаголовок шапки «Подсветка, обновление, контраст» остаётся).
