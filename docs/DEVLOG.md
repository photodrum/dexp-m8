## 2026-11-11 — замечание 1, проба контраста, чистка EinkActivity (Opus)

- **Замечание 1 (белый кадр после диалога права на холодном старте).** Причина подтверждена по коду: `requestStorage()`
  из `onCreate` идёт до первого фокуса окна, `onWindowFocusChanged(false)` не приходит, `cleanOnFocus` не ставился.
  Правка: `onRequestPermissionsResult` сам заказывает очистку — окно в фокусе → `cleanRefresh()` сразу, нет →
  `cleanOnFocus = true`. Чтобы при обычном порядке (фокус ушёл → ответ → фокус вернулся) не было двух белых кадров:
  если очистка уже заказана (`cleanOnFocus`) — ничего; если уже прошла по фокусу, пока шёл запрос (`cleanedWhileAsking`) — ничего.
  Проверка на книге: удалить приложение, поставить заново, запустить → в трассе `storage: granted|denied`, затем
  ровно один `eink: clean after dialog`, следа «РАЗРЕШИТЬ» нет.
- **Замечание 4 (контраст), только проба.** `Sys.gamma()` / `setGamma()` — `android.os.SystemProperties` рефлексией,
  ключ `sys.gray.gammalevel`. `Sys.probeGamma()` один раз за процесс при входе на B37 пишет **текущее** значение обратно
  (экран не меняется) и оставляет в трассе `sys gamma probe: cur=N write=OK|FAIL`; при отказе — ещё строка
  `sys gamma set FAIL: <исключение>`. Ожидание: FAIL (SELinux, `property_service` не даёт обычному приложению `sys.*`).
  Интерфейс B37 не менялся — ждём макет. Если OK — Sonnet делает ползунок по новому B37 через `setGamma`;
  если FAIL — варианты: убрать контраст из B37 или показывать значение без записи (решает пользователь).
- **Чистка `EinkActivity`:** удалены неиспользуемые `stub`, `repaint`, `schedule`, `showCrash`, дубль `show` (остался `changeTo`).
  `popTo` оставлен — понадобится для возврата из глубоких экранов.
