# 2026-11-19 — B74 Bluetooth-устройства (Opus), подробно

Запись в `docs/DEVLOG.md` — «B74». Здесь — решения, системные вызовы и что осталось.

## Слои

- `core/BtDevices.kt` — только вызовы системы. Открытые API: `getBondedDevices`, `startDiscovery` /
  `cancelDiscovery`, `createBond`, `getProfileProxy` (A2DP, HEADSET, HID = 4). Скрытые, через
  рефлексию (на 8.1 ограничений на скрытые API нет, они появились в P):
  `BluetoothA2dp/Headset/InputDevice.connect|disconnect(BluetoothDevice)` — проверяют только
  BLUETOOTH_ADMIN; `BluetoothDevice.isConnected()` (ACL), `getBatteryLevel()` (новое в API 27);
  `BluetoothAdapter.setScanMode(mode, duration)` — видимость на 120 с без системного диалога
  `ACTION_REQUEST_DISCOVERABLE`. На книге `setScanMode` вернул `true` с первого раза.
- `ui/SetBtScreen.kt` — B74. Модель кадра (`build`) собирается из системы и ожиданий экрана;
  `snapshot` — все тексты подряд: перерисовка только при изменении текста. Таймер раз в секунду
  работает, пока идёт поиск, подключение/отключение/сопряжение или видимость, — иначе экран
  стоит. Ожидания: 25 с без ответа → «Не удалось подключить» / «Сопряжение не завершено».
- B38: строка «Сопряжённые устройства» (1430…1588) открывает B74; значение —
  `BtDevices.summary()`: имя подключённого, иначе «N устройств» / «Нет устройств», выключен — «—».
  Пересчёт по событиям (`ACTION_STATE_CHANGED`, ACL, bond), не на каждом кадре. Зона тумблера
  Bluetooth сужена с 190 до 182, чтобы не наезжать на строку двери.

## Отступления от макета (в макете таких состояний нет)

- Bluetooth выключен — абзац «Включите Bluetooth…» вместо разделов.
- Сопряжённых нет — строка «Нет сопряжённых устройств».
- Прокрутки нет: всего 8 строк (низ 1818), сопряжённых до 5; лишние доступные — «· ещё N» в строке
  поиска. Доступные — только с именем, сильный сигнал первым.
- Подписи состояния: «Не видна · коснитесь, чтобы показать на 2 мин», «Включается…»,
  «Подключение…», «Сопряжение…», «Коснитесь — Android попросит доступ к местоположению».
- Род в «Подключены/Подключена/Подключен», «Сопряжён/Сопряжены» — по виду устройства (`Kind.end`).
- Стрелка `next` у сопряжённого — как в макете, но касание подключает/отключает: экрана
  устройства («Забыть») в макете нет — вопрос в `docs/DESIGN_QUESTIONS.md`.

## Проверено на книге (2026-11-19)

- `--es screen bt`: поиск стартует сам, «Идёт поиск · 3 с» тикает, найдены `KD-49XG8096` и
  `realme 8i`; через ~12 с строка «Искать устройства · Коснитесь, чтобы искать снова».
- Грабля, исправлено: телевизор Sony (класс AUDIO_VIDEO, видео) подписывался «Наушники» — всё
  неизвестное в AUDIO_VIDEO шло в наушники. Теперь наушники — только HEADPHONES / WEARABLE_HEADSET /
  HANDSFREE, видео-классы — «Телевизор», остальное — «Устройство».
- Касание верхней панели — `bt: visible true -> true`, подпись «Видна другим устройствам 2 мин».
- B38 (`--es screen net`): значение строки «Нет устройств», касание строки открывает B74.
- Не проверено (нужно устройство рядом): сопряжение (диалог PIN системы), подключение A2DP/HID,
  заряд, отключение, «Сопряжение отменено». Сопряжённых устройств у книги нет.

## Значок Bluetooth в статус-баре (2026-11-19, просьба пользователя)

`StatusBar`: иконка `bluetooth` из снимка, слева от Wi-Fi через зазор 24.7 — тот же, что между
Wi-Fi и батареей. Wi-Fi выключен — Bluetooth встаёт на его место у батареи. Состояние —
`ACTION_STATE_CHANGED`, значок только в `STATE_ON`. На книге: тумблер B38 выключает — значок
пропал, включает — вернулся. В макете статус-бара значка нет — вопрос в `docs/DESIGN_QUESTIONS.md`.

**Размер и толщина (правки пользователя 2026-11-19).** Сначала коробка значка была равна коробке
`wifi` (38.4×40.2) — Bluetooth выходил крупнее и выше. Замер по снимку: видимый глиф `wifi`
занимает 23 px своей коробки (39…61 по y), глиф `bluetooth` — почти всю. Затем штрих оказался
тонким: иконка из снимка имеет штрих 3, при коробке 22.2 он ужимается до 1.6 px, а у `wifi` на
экране 3.6. Сделан вариант **`bluetoothBold`** в `tools/icon_specs_extra.txt` (штрих 5.5, форма та
же) и `IconSpecs.kt` перегенерирован. Итог: коробка 11.42×21.7 → 20, центр `BT_CY` 50.8.
Проверено замером по снимку: `bt` 39…62, `wifi` 39…61 — одна высота и линия, штрих 9 px на разрезе
против 6 у Wi-Fi (визуально одинаково). Штрих 6.8 пробовали — линии слипаются, глиф теряет просвет.

## Сопряжение и подключение на книге (2026-11-19, наушники RHA TrueConnect)

- Сопряжение: `bt: bond 00:00:C0:00:6C:2C -> true`, устройство в «Сопряжённых», на B38 «1 устройство».
- Подключение: `connect … HEADPHONES proxies=[4, 2] -> true` — пришли прокси HID (4) и A2DP (2),
  HEADSET (1) нет. A2DP: `Pending` → через ~20 с `Disconnected`; экран после 25 с — «Не удалось
  подключить». Разобрать: были ли наушники включены и вне футляра; нет ли HEADSET-службы на прошивке
  (`dumpsys bluetooth_manager` — профили).
