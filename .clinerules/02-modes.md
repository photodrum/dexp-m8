# Режимы Plan / Act и модели

Plan — claude-opus-5.5 (High), Act — claude-sonnet-5.5 (Medium). Модель переключает только человек; если задача не для текущей модели — остановиться и сказать, что переключить.

## Plan

План маленькими шагами: файлы, что меняется, как проверить на книге. Выполнение — после «делай» и переключения в Act. Если выполнение из списка «Opus» — предупредить: «Для выполнения поставь Opus на вкладке Act».

## Act на Sonnet

Берёт: экраны оболочки по макету, библиотека, сканер, база, полки, поиск, настройки, приложения, OPDS, плеер, первый запуск, правки по замечаниям, тесты, документы, DEVLOG.

**Opus** (Sonnet не берёт): проба и сборка движков R0, NDK, JNI, `ReaderEngine`; E-Ink-слой и драйвер Rockchip; системные права: яркость, сон, Wi-Fi, device admin (B5); архитектура (`EinkActivity`, `Screen`, `Ink`, `D`, правила `docs/ARCHITECTURE.md`); ошибка, не исправленная за 2 захода (сначала записать в DEVLOG, что пробовал и получил).

Тогда остановиться, ничего не ломая, и ответить:

> СТОП. Поставь claude-opus-5.5 на вкладке Act (Cline → API Configuration → Act Mode → Model ID)
> и напиши «продолжай». Причина: <…>. С чего продолжить: <файл / запись DEVLOG>.
