## СЛЕДУЮЩИЙ ШАГ

гнездо и обложка с корешком, название Literata 84/600, название/автор/прогресс, подсказка
«Нажмите кнопку питания». Показ — за 20 с до системного гашения (`EinkActivity.planSleep`):
своего гашения нет, кадр рисуется на горящей панели и остаётся на выключенном E-Ink. Системная
заставка (DreamService) на прошивке отсутствует — поэтому своя. Пробуждение — касание, свайп,
клавиши, «Назад»; следов заставки не остаётся (полная перерисовка). «Сон» на B5 рисует B19 и
через 700 мс гасит экран. `typecheck` 259/0, `check_design` 331/249/0, `assembleDebug` ок.
Подробно — `docs/archive/DEVLOG-2026-11-18-b19.md`.

Дальше — **B20 низкий заряд** (диалог по макету: «Заряд 9%», «Осталось примерно 2 часа чтения»,
«Режим энергосбережения», «Позже»/«Включить экономию»). Это тоже Opus: системные права
и выключение устройства при 3 %. Модель на вкладке Act уже `claude-opus-5.5`.

⚠️ **Картинку на выключенном экране задаёт прошивка**: после гашения композитор рисует
`/vendor/media/standby.jpg` / `poweroff.jpg`, кадр B19 виден только пока горит подсветка.
Своя картинка «Книга закрыта» — `design/boot/` + `tools/standby_install.sh` под root по adb
(из APK нельзя). Подробно — `docs/archive/DEVLOG-2026-11-18-standby.md`.

⚠️ `pm clear` на книге сносит данные целиком (база + `shell.xml`). Восстановлено из
`~/dexpm8-backup-2026-11-18` (sha256 сошёлся, 532 книги). Для проверки мастера хватает
`--es screen first`.

⚠️ На книгу ставить только `gradle assembleDebug` (5,7 МБ): `tools/build.sh` собирает APK без
натива — читалка падает с «.so не загрузилась».

Скриншоты проверки — `/tmp/d.png` (заставка), `/tmp/j.png` (возврат в книгу), `/tmp/l.png`
(без заряда). В репозиторий не кладём.

(`docs/BUILD.md`, «Подпись APK»): потеря ключа = снос данных при следующем обновлении.
