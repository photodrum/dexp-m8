# DEVLOG 2026-11-19 — B71 «Часовой пояс»

Подробности к записи `docs/DEVLOG.md` (п. 13, экран B71). Модель — Opus (Act).

## Что сделано

- `core/Sys.kt`: `zone()`, `autoZone()`, `setZone(id)`. Свойство `persist.sys.timezone`, доступ
  рефлексией к `android.os.SystemProperties` — тем же приёмом, что контраст (`gamma`).
- `core/Zones.kt` — 11 действующих поясов России (город, смещение, описание) и подпись пояса
  `label(id)` для B41/B60. Раньше подпись собиралась двумя копиями `zoneName` в этих экранах;
  теперь копии убраны.
- `ui/SetTimeZoneScreen.kt` — B71 по числам макета: шапка, панель 41,250 1321×160, раздел
  «РОССИЯ» 59,450, панель 41,498 1321×920, строки шагом 152 от 527, галочка `check` 1282.7,
  пагинация B6 (желоб 614.3,1766 175.5×29.2).
- Двери: строка «Часовой пояс» на B41 (780…924) и на B60 (710…864). Отладка —
  `--es screen zone`.

## Решения

1. **`AlarmManager.setTimeZone` из CONTEXT не подходит.** Он требует `SET_TIME_ZONE` — право
   уровня подписи платформы, `WRITE_SETTINGS` его не заменяет. Проверено: у пакета
   `WRITE_SETTINGS` есть, `SET_TIME_ZONE` нет.
2. **`setprop` из процесса приложения работает.** Проверено на книге из `run-as` (uid 10052):
   `setprop persist.sys.timezone Asia/Samara` меняет время сразу, значение ложится в
   `/data/property/persist.sys.timezone` и переживает перезагрузку. `su` приложению недоступен
   (`sh: su: can't execute: Permission denied`), и он не нужен.
3. **Кеш зоны в процессе сбрасывается вручную.** `TimeZone.getDefault()` в JVM кеширует пояс,
   а рассылка `TIMEZONE_CHANGED` после `setprop` не приходит (её шлёт только `AlarmManager`, и она
   защищённая). Без `TimeZone.setDefault(null)` часы статус-бара оставались в старом поясе:
   на снимке после смены Камчатки было 4:26, а `date` — 23:26. Это нашлось при первой проверке
   на книге; после правки часы совпадают с `date`.
4. **Список 11 строк, а не 6 как в макете.** Поясов России после 2014 года 11 без летнего
   времени; шесть строк макета — это текущий пояс наверху плюс пять по возрастанию смещения.
   Экран собирает так же: текущий первым, остальные `sortedBy { offsetMin }`. Проверено, что
   порядок совпадает с макетом при московском поясе.
5. **«Определять по сети» — только чтение.** `Settings.Global.auto_time_zone` пишется лишь с
   `WRITE_SECURE_SETTINGS`; на книге `settings put` из процесса оболочки отказывает
   (`Security exception: You need MANAGE_USERS`). Тумблер показывает состояние системы (на книге 1),
   касание по строке не реагирует — как «Время по сети» на B41.
6. **Пагинация по 6** (как у B75 по 7): под 11 строк места в панели 920 не хватает, а желоб B6
   помещается в пустоте ниже панели (1418…1872).
