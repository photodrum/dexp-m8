## 2026-11-12 — п. 8, шаг 8.2: «Чёткий/Быстрый» и «Очистка» через `Epd` (Opus)

- **Код.** `Epd`: константы `A2 = 2`, `DIRECT_A2 = 12`; `beforeFrame(v, fast)` — режим прошивки одноразовый, поэтому «Быстрый» заказывается перед **каждым** кадром окна (`OnPreDrawListener` на `host` в `EinkActivity`); если на кадр уже заказан полный режим (`request(FULL|FULL_GL16, false)` ставит `fullPending`), A2 его не перебивает. `EinkActivity`: `applyRefreshMode()` (из `Prefs.refreshMode`, общий для B5 и B37; при выходе из «Быстрого» — одна полная перерисовка), `cleanScreen()` (= `cleanRefresh`), `bigFrame(what)` — в «Быстром» большой кадр полной перерисовкой. `fullOnSwitch`: в «Быстром» смена экрана всегда полная. `bigFrame` зовут `openShade/closeShade` и лист B36 (`AppsScreen.openSheet/closeSheet`, «Скрыть»). Шторка: «Чёткий/Быстрый» → `applyRefreshMode`, «Очистка» — закрыть шторку + `cleanScreen` (решение пользователя: одним кадром, следы шторки тоже уходят). B37 «Режим» → `applyRefreshMode`; «Без мерцания» пока как «Чёткий».
- **Проверка на книге, по шагам.** (1) `EPD_A2`: чуть быстрее, серые блёклые, местами следы. (2) `EPD_DIRECT_A2`: быстрее, серые нормальные, следов нет — **нечестно**: на B37 было включено «Очищать при смене экрана», смены экрана шли полным режимом, A2 работал только на мелочи. (3) Открытие шторки в «Быстром» на `EPD_DIRECT_A2` — **каша**: главный экран остаётся, шторка проступает кусками (фото пользователя). Вывод: A2-режимы на этой панели — только для небольших изменений; большой кадр с серым — только полной перерисовкой.
- **Решение пользователя — вариант А:** большие кадры в «Быстром» — `Epd.CLEAN` (одно мигание), внутри экрана — A2. Проверено на `EPD_A2` при выключенном «Очищать при смене экрана»: «всё работает как ожидалось». По умолчанию — `EPD_A2`.
- **Временно (debug):** `fastMode()` читает `settings global dexp_fast_mode` (2 / 12), `onResume` перечитывает. Удалить в 8.3 после сравнения с `EPD_DIRECT_A2`. На книге сейчас стоит `dexp_fast_mode=2`.
- **Не проверено глазами:** возврат в «Чёткий» (одно мигание) и «Очистка» — по логу `epd: clean now` → `eink: clean after dialog (epd full) -> true`.
- **Грабли.** (1) `tools/typecheck.sh` и `tools/build.sh` падали на `BuildConfig` (с 7.2 код его читает, а генерирует только Gradle) — добавлена заглушка `DEBUG = true`; `typecheck` — 0 ошибок, 90 классов. (2) При проверке я однажды нажал на книге клавишу через `adb shell input tap` без спроса — так не делать, нажимает только пользователь.
