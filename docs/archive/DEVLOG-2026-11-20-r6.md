# R6 — чтение вслух системным TTS (п. 19)

Дата: 2026-11-20. Модель: Opus (Act). Проверено на книге.

## Разведка: движок на прошивке

- `settings get secure tts_default_synth` → `com.google.android.tts` (`/system/app/TTS/TTS.apk`).
  Запасной `com.svox.pico` (`/system/tts/lang_pico`) знает только de/en/es/fr/it — русского нет.
- Русский голос **уже скачан офлайн**: `/data/user_de/0/com.google.android.tts/app_voices_greco_v15/ru-ru-x-dfc`,
  32 МБ (в интерфейсе движка «Набор голосов 1, 64 МБ»). `/data/data/.../app_voices` при этом пуст —
  по нему судить нельзя. Экран движка для проверки:
  `am start -n com.google.android.tts/.local.voicepack.ui.VoiceDataInstallActivity`.
- В трассе приложения: `tts: lang ru=1 default(ru_RU)=1`, `tts: init ok ru=true rate=140`.
- Сеть не нужна, Google Play Services на прошивке нет — синтез локальный.

## Что сделано

- **Натив** (`engines/reader_jni.cpp`): буфер `pageTextNative` 400 → 8192 байт. Было
  «первые символы» для строки закладки (R4.1); при 400 байтах голос получал бы ~200 знаков
  кириллицы — десятую часть страницы. Сам `dexp_reader_page_text` длину отдавал и раньше.
- **`core/Speech.kt`** — обёртка над `TextToSpeech`: `init` один раз на оболочку
  (`EinkActivity.speech`), проверка `isLanguageAvailable` (русский, затем локаль системы),
  скорость, дробление на куски ≤ 3500 знаков по границам предложений, очередь `QUEUE_ADD`
  (бесшовная склейка), `UtteranceProgressListener.onDone` последнего куска → `onPageDone`.
- **`ReaderMenu`**: `ACT_TTS`, `BTN_SPEAK = 3`; кнопка «Вслух» вдавлена, пока идёт чтение
  (вида «читает» в макете нет — вдавленность уже значит «включено» на B39/B27).
- **`ReaderScreen`**: `toggleSpeech()` — старт с текущей страницы (меню закрывается), повторное
  нажатие — стоп; текст берётся в `Engine.worker` с `Engine.syncPage(cur)` (иначе prefetch
  подсунул бы соседнюю страницу); страницы без текста (обложка, иллюстрации) пропускаются,
  до 40 подряд; по концу страницы — `show(cur+1)` и текст следующей; ручное листание, уход
  с экрана и `onPause` голос останавливают; подпись под страницей — «Читаю вслух · N%».
- **`keepScreenOn`** на время чтения: иначе таймер сна гасит экран посреди главы.
- **`Prefs.ttsSpeed`** (умолчание 140 %), строки на B39 нет — вопрос дизайну.

## Проверено на книге (APK `f80d86a6…`)

- EPUB «Тень императора»: стр. 1–5 — обложка и иллюстрации, голос их пропустил
  (`tts: стр.N без текста — дальше`), чтение началось со стр. 7 (1420 знаков).
- Автолистание: `tts: page done 6` → `tts: листание -> стр.8` → `tts: read page=7 знаков=2964`.
  Экран: стр. 8, «Читаю вслух · 4%».
- Меню во время чтения: «Вслух» вдавлена (снимок `s7_menu.png`), повторное нажатие — `tts: stop`.
- Ручное листание правой третью: `tts: stop`, подпись вернулась к «4% · 3 стр. до конца главы».
- «Домой»: `tts: stop` в `onPause`, `STREAM_TTS` активных треков у пакета нет.
- Звук подтверждён `dumpsys audio`: `STREAM_TTS ... state:started`, logcat движка —
  `For default lang ru-ru is name ru-RU-language (ru-ru-x-dfc-server)`.

## Что не проверено

- На слух (нет наушников у машины): темп 140 %, паузы между кусками. Уши — человеку.
- Закрытый экран во время чтения: экран не гаснет (`keepScreenOn`), но жест «Сон» из B5 и
  таймер B40 не проверялись.
- Скорость/громкость для чтения вслух в настройках: строки в макете нет.
