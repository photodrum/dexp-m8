# B20 — низкий заряд (2026-11-18)

Пункт 13, диалог низкого заряда. Подробности к записи `docs/DEVLOG.md` от 2026-11-18.

## Что на макете и что решено

`design/v5/B20.json` — диалог поверх затемнённой страницы книги: «Заряд 9%», «Осталось примерно
2 часа чтения», пояснение «Подключите книгу к зарядке через USB-C. При 3% оболочка запомнит
страницу и выключит устройство», строка «Режим энергосбережения» (без Wi-Fi и подсветки до
зарядки) с тумблером, кнопки «Позже» (выпуклая) и «Включить экономию» (тёмная, главная).

Расхождение в самом макете: подпись кнопки — «Включить экономию», а тумблер строки нарисован
**включённым**. Решение: диалог показывает текущее состояние `Prefs.saverApplied`, тумблер —
индикатор (касание строки = «Включить экономию»), а не отдельный выбор. Так макет не врёт:
в момент показа режим ещё не включён.

## Когда показывается

`EinkActivity.checkBattery()` — один вход, три исхода:

| Заряд | Что делает оболочка |
|---|---|
| идёт зарядка | снимает экономию: Wi-Fi и подсветка возвращаются (`Power.saverRelease`), диалог убирает |
| ≤ `Power.OFF_AT` (3 %) | один раз за разряд: `saveNow()` читалки, заставка B19 (`curtain`), меню питания (`PowerService`) |
| ≤ порога экономии | `Prefs.saver` включён — экономия включается сама (так обещает подпись B40 «Включится при 15 %»); выключен — диалог B20, **один раз за разряд** |

Порог экономии — `Settings.Global.low_power_trigger_level` (чтение; записи у обычного приложения
нет), пусто — 15 %. Проверки: `EinkActivity.onCreate` после первого кадра, `onResume`
(приёмник батареи живёт только на переднем плане), `onUserInteraction` (не чаще касания).

## Код

- `core/Power.kt` — `read()` (липкий `ACTION_BATTERY_CHANGED`), `saverAt()`, `hoursText()`
  (20 ч на полный заряд: 9 % → «примерно 2 часа чтения», ниже 45 мин — «меньше часа»),
  `saverApply()`/`saverRelease()` — Wi-Fi и подсветка, что было, помнится в `Prefs`
  (`saverApplied`, `saverWifi`, `saverBright`).
- `ui/LowBatteryScreen.kt` — B20 по числам макета; затемнение — через `current().dimmed`
  (тот же фильтр, что у шторки B5), сам диалог — второй View в `host`.
- `EinkActivity` — приёмник `batteryWatcher`, `showLow`/`closeLow`/`lowLater`/`lowSaver`,
  `shutdownNow`; в `onBackPressed` и `changeTo` диалог снимается вместе с экраном.
- `SetSleepScreen` — выключили «Экономию заряда» → `power.saverRelease()` сразу, не дожидаясь
  зарядки.

## Решения и чего нет

- **Своего выключения питания из APK нет**: `PowerService.GLOBAL_ACTION_POWER_DIALOG` открывает
  системное меню (решение п. 8, как «Выключение» на B5). Служба не включена — `lockNow` (если
  admin), иначе остаётся заставка B19.
- **Device admin не запрашиваем**: `sleepNow()` выскочил бы системным запросом права в момент
  разряда. Выключение идёт через меню питания, админ для него не нужен.
- **Системную экономию (`PowerManager`) не трогаем**: на прошивке не проверена; «без Wi-Fi и
  подсветки» — два своих действия, как написано на B40 и в макете.
- «Осталось примерно N часов» — оценка, не замер. Число `FULL_MINUTES` в `Power` (20 ч); уточнить
  на книге, когда будет известен полный заряд и время чтения.

## Проверено на книге (2026-11-18/19, adb `dumpsys battery` вместо настоящего разряда)

| Что | Итог |
|---|---|
| тумблер B40 включён, 14 % без питания | `power: saver on wifi=true bright=45`; Wi-Fi 0, подсветка 0 — экономия включилась сама, диалога нет |
| зарядка (`set ac 1`, 30 %) | `power: saver off wifi=true bright=45`; яркость вернулась 115, Wi-Fi 1 |
| тумблер B40 выключен, запуск на 14 % | `power: low 14% (saver at 15, applied=false)` — диалог B20 по макету: «Заряд 14%», «примерно 3 часа чтения», тумблер выкл, затемнение фона (G12 → 137, фильтр `dimmed`) |
| «Позже» | `power: low closed`, экран под ним как был |
| 13 %, 8 %, 10 % после «Позже» | повтора не было (`lowShownAt` держит); после перезапуска на 10 % диалог снова показан один раз |
| «Включить экономию» | `power: saver from B20 -> true`, Wi-Fi 0, подсветка 0, `saver_applied=true`, `saver_bright=45`; тумблер B40 остался выключенным, как и задумано |
| 3 % | `power: off at 3%` → `sleep: curtain` (заставка B19) → `power: off — нет службы питания`, экран погас (`mWakefulness=Asleep`, `lockNow` при admin) |
| зарядка после 3 % | `power: saver off wifi=true bright=45`, яркость 115, Wi-Fi 1; повторного выключения нет |
| «Назад» в диалоге на 11 % | `power: low 11%` → «Назад» → `power: low closed`, процесс жив |

Грабли проверки: `dumpsys battery set level` **не меняет** `status` — при `status: 5` (FULL) код
считает книгу заряжающейся и диалог не покажет; нужен ещё `dumpsys battery set status 3` (разряд)
и `set ac 0` + `unplug`. Тумблер B40 правился правкой `shared_prefs/shell.xml` через
`run-as` (debug): `sed -i` в `adb shell run-as sh -c` ломается на кавычках — делать через
`pull → правка на хосте → push → cp`.

**Не проверено на настоящем разряде**: поведение при реальном падении заряда (порог 15 % от
системы) и время показа — всё это шло через подмену `dumpsys battery`.
