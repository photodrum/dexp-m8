# Дизайн-токены из Penpot

Источник: файл **«UI»**, страница **v5**, 46 бордов 1404×1872.
Снято живьём через MCP, не по памяти. Формат: константы для `Tokens.kt`.

## Палитра G0…G15

Шаг 17 (`0x11`). Все 46 бордов проверены — посторонних цветов нет.

| Токен | Hex | В коде | Назначение |
|---|---|---|---|
| G0 | `#000000` | `T.G0` | чёрный (1 вхождение) |
| G1 | `#111111` | `T.G1` | основной текст |
| G2 | `#222222` | `T.G2` | — |
| G3 | `#333333` | `T.G3` | тёмная клавиша (главная кнопка), заливка прогресса |
| G4 | `#444444` | `T.G4` | вторичный текст, контур иконок |
| G5 | `#555555` | `T.G5` | подписи, неактивные сегменты |
| G6 | `#666666` | `T.G6` | плейсхолдер |
| G7 | `#777777` | `T.G7` | корешок обложки |
| G8 | `#888888` | `T.G8` | тень тёмной клавиши |
| G9 | `#999999` | `T.G9` | приглушённая иконка |
| G10 | `#AAAAAA` | `T.G10` | тень, внутренняя тень, приглушённый текст |
| G11 | `#BBBBBB` | `T.G11` | обод углубления, разделители |
| G12 | `#CCCCCC` | `T.G12` | дно углубления, обложка |
| G13 | `#DDDDDD` | `T.G13` | фон экрана |
| G14 | `#EEEEEE` | `T.G14` | поверхность «пластика» |
| G15 | `#FFFFFF` | `T.G15` | блик, текст на тёмной клавише |
