## Решения

1. **Поиск — по тёмной клавише «Найти», а не после каждой буквы.** `Engine.search` на 1946
   страницах идёт 758 мс — на каждую букву это неприемлемо. На B21 поиск идёт по базе и дешёвый,
   поэтому там он «живой»; здесь — по «Найти» и при смене вкладки. Набранное, но не найденное,
   помечается «Запрос изменился»: старый список не висит под новым запросом.
2. **«Текущая глава» — фильтр по страницам главы**, а не второй поиск: `Engine.search` ищет по
   всей книге, глава — это диапазон `chapterStart…chapterEnd` из оглавления. Нет оглавления —
   границ нет, вкладка показывает всю книгу. Счётчик страниц и подпись «найдено N» считаются по
   отфильтрованному списку (иначе «1 / 100» при одном совпадении — проверено и исправлено).
3. **«Заметки» — из базы, а не из движка.** Цитаты и заметки живут в `bookmarks` (v11); вкладка
   читает их при открытии экрана. Пока B50–B52 нет, список пуст — вид проверен.
4. **Переход по совпадению — `gotoPos` (xpointer), `page` запасным путём.** Тот же приём, что R4.2
   у закладок: после смены кегля номер страницы врёт, позиция — нет.
5. **База v11 — таблица пересоздаётся, а не дополняется.** `UNIQUE (book_id, pos)` не дал бы
   цитате начаться там же, где стоит закладка страницы; `ALTER TABLE` в SQLite ограничения не
   меняет. Старые закладки переезжают с `kind = 0`. `marks()` теперь отдаёт все три вида, а
   подпись вкладки «Закладки · N» считает только закладки (`kind = 0`) — цитаты и заметки будут
   отдельной вкладкой B27.
6. **DjVu — поиска нет.** У скана нет текстового слоя: `openSearch` у DjVu не открывается вовсе
   (в трассе «b28: DjVu — поиска нет»), как и в READER_SPEC, R4.

## Грабли

1. **`ALTER TABLE … RENAME` тащит индекс за собой.** После `RENAME TO bookmarks_old` индекс
   `bookmarks_book` остаётся с тем же именем, и `createBookmarks` падает на
   `index bookmarks_book already exists`; миграция обрывается, `user_version` остаётся 10, а
   приложение пишет «Книга не найдена» (падение чтения схемы). Лечение: `DROP INDEX IF EXISTS`
   между `RENAME` и созданием таблицы.
2. **`kotlinc` без JDK.** `tools/typecheck.sh` падает на `java: command not found` —
   `export JAVA_HOME=$HOME/.local/jdk PATH=$HOME/.local/jdk/bin:$PATH` (уже в `docs/BUILD.md`).
3. **`am start --es reader <файл>` запускает самотест** `EngineSelfTest`, а не читалку. Для проверки
   глазами — `--es read <_id>` (id из базы: `run-as … sqlite3 databases/library.db`).
