# 2026-11-21 — B32 «Статистика»: три ошибки графика и счётчика (Opus)

Проверка на книге после п. 22: на экране «Всё время» — **0 мин читали всего, но 534 книг закончено**.
Разбор дал три ошибки; все исправлены и проверены на книге.

## 1. «Книг закончено» считало весь фонд

`LibraryDb.finishedBetween` (вызывается из `stats(from, to)` и из ветки «Всё время»):

```kotlin
val lo = if (from <= 0) 0L else dayStart(from)
"SELECT COUNT(*) FROM books WHERE finished >= ? AND finished < ?"
```

У «Всего времени» нижняя граница равна `0`, а `books.finished` — `INTEGER NOT NULL DEFAULT 0`,
где ноль значит «книгу не дочитывали», а не полночь 1970-го. Условие `finished >= 0` пропускало
**все** 534 книги библиотеки. Проверка в базе на книге: `count(*) where finished = 0` → 534,
`finished > 0` → 0.

Правка: `WHERE finished > 0 AND finished >= ? AND finished < ?`. Порядок важен для читаемости, на
план запроса не влияет (индекса по `finished` нет, таблица маленькая).

Проверено на книге: «Всё время» → «0 книг закончено»; временно выставленный `finished` у книги
`_id = 1` → «1», после отката снова «0». «Месяц», «Год», «Неделя» не изменились.

## 2. Столбики недели и «всего времени» стояли зеркально

`daysBack(day)` возвращает **0 для сегодня** и растёт назад, а индекс столбца 0 — самый старый
день периода (ось слева «15», справа «21»). Один и тот же индекс использовался и для оси, и для
данных, поэтому столбик сегодняшнего дня вставал под подписью самого старого числа: на неделе
20 ноября рисовалось под «16».

Правка в `StatScreen.chart`:

```kotlin
val i = if (period == PERIOD_MONTH) LibraryDb.ymd(day)[2] - 1
        else (n - 1) - daysBack(day)
```

Месяц и год индексируются прямо (день месяца − 1 / номер месяца в отрезке), их это не касалось.
Проверено на книге: неделя 15…21 — столбик под «20», совпадает с «лучший день 20 ноября»;
«Всё время» — столбик у правого края под «21» (сегодня).

Побочно исправилась и тёмная последняя засечка: `i == n - 1` теперь действительно сегодняшний
день, а не самый старый.

## 3. Ось «Всё время» без месяцев

Шаг подписи 7 дней, период 31 день — ось пересекает границу месяца, а показывались только числа:
«22, 29, 5, 12, 19, 21». Замечание пользователя: «непонятные цифры, заканчиваются на 20».

Правка: `axisLabels` зовёт новый `dayLabel(day, prevMonth, withMonth)` — месяц дописывается у
первой подписи и там, где он сменился: «22 окт, 29, 5 ноя, 12, 19, 21». У недели месяц не
дописывается (он в подзаголовке «15–21 ноября 2026», лишний текст теснит семь подписей).
Название — из уже имеющегося `MONTH_SHORT` («янв»…«дек»).

Проверено на книге: подписи «22 окт / 29 / 5 ноя / 12 / 19 / 21», не наезжают друг на друга
(шаг 323 px, подпись «22 окт» ≈ 90 px).

## Замечание на будущее (не делалось)

Ось стоит под каждым седьмым столбцом, но в «Неделе» подписаны все семь дней — при узких числах
нормально, при двузначных плотно. Если появится жалоба — подписывать через день.
