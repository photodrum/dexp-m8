## Дальше (roadmap)

Пересмотрено 2026-11-08. Порядок: **сначала оболочка, потом читалка**. Читалка — свой UI
на `Canvas` + готовые движки (CREngine для FB2/EPUB/MOBI/TXT/RTF/DOC, MuPDF для PDF/CBZ,
DjVuLibre для DjVu). Своя вёрстка страниц на C и свой EPUB сняты. Подробно —
`docs/READER_SPEC.md`. Как работать с макетами — `docs/DESIGN_USAGE.md`.

**Оболочка**

  краю). Какое оптическое начертание (opsz) Literata в макете.
