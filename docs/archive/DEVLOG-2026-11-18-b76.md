## Решения

- **`PackageInstaller`, а не `ACTION_INSTALL_PACKAGE`:** на API 27 `file://` в интенте даёт
  `FileUriExposedException`, а `android.support.v4.content.FileProvider` в проекте нет (AndroidX
  не подключаем). Сессия берёт APK потоком и обходится без провайдера.
- **Порядок строгий:** `.part` → `sha256` → переименование. Сумма из 64 нулей в манифесте
  считается отсутствующей: `why = "в манифесте нет суммы"`, в установку ничего не отдаётся.
- **Прогресс без полосы:** в макете B76 полосы нет, поэтому проценты идут в подпись кнопки
  («Скачиваем 40 %»), перерисовка — на каждый новый десяток (порог 10 % в `download`).
- **Тумблер «только при зарядке» работает,** а не хранится: перед скачиванием проверяется
  `ACTION_BATTERY_CHANGED`; на батарее экран просит поставить на зарядку.
- **«Позже»** пишет `Prefs.updateSkipCode` — эту версию пропустит автопроверка при старте.
- **Дверь в B76** — новая строка в «ОБСЛУЖИВАНИИ» B43 (решение человека 2026-11-18);
  панель 350 → 525, шаг строк 175; нижняя кнопка B43 осталась проверкой, как в макете.

## Грабли

1. **`STATUS_PENDING_USER_ACTION` (−1) — не отказ.** Первый прогон на книге дал в трассе
   `install: status=-1`, экран написал «Система не поставила обновление». На самом деле система
   отдаёт в `EXTRA_INTENT` свой диалог подтверждения. Лечение: ветка в `Receiver`, которая
   запускает этот интент (`FLAG_ACTIVITY_NEW_TASK`) и ждёт второго сообщения. Без неё установка
   не начинается вообще.
2. **Успешная установка убивает наш процесс** (`Force stopping … installPackageLI`), поэтому
   «Готово» на B76 не увидеть: оболочка стартует заново, экран открывается уже с новой версией.
   Приёмник остаётся нужен для отказов (подпись, место) — там процесс жив.
3. **`dumpsys package` после установки показывает старое** (`versionCode=2`) из-за кеша;
   правду дают `pm dump` и `flags=[ … ]` без `DEBUGGABLE`.
4. **Иконка `download` в `IconSpecs` записана без суффикса размера** (`download|35.3|40.9`):
   `icons.draw(c, "download@35.3x40.9", …)` рисует пустоту молча. На B43 поймано снимком.
5. **Порт 8000 на этой машине занят** чужим процессом (403 на все файлы): для отладочной раздачи
   брать 8137 и `--bind 0.0.0.0`, иначе книга не достучится.
