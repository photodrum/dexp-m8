## 2026-11-26 — 25.1в: оценка и поиск — `Eval.kt`, `Search.kt`, `Level.kt` (Opus)
- Перенос Evaluation/Search/Value из Pulse (MIT): материал + пара слонов + подвижность + темп; итеративное углубление, альфа-бета, поиск покоя, главная линия, «мат в N».
