# Шахматы — план и решения (2026-11-21, п. 25 ROADMAP)

Источник: разговор в Plan-режиме 2026-11-21 + проверки с хоста. Кода нет, APK не менялся.

## Решения человека

- Шахматы — **в стиле оболочки** (Canvas, палитра G0–G15, без анимаций) и **внутри** APK, а не отдельным приложением.
- Нужны: игра против компьютера **без сети** и игра с людьми **по сети**, но **без ручного токена**.

## Почему не lichess-org/mobile

- Flutter 3.50, `minSdk 26`, Firebase, AndroidX, `multistockfish`, `lc0`/onnxruntime; лицензия **GPL-3.0** — несовместима с нашей GPL-2.0-only (один APK/процесс). Свой рисунок и E-Ink-правила Flutter не соблюдает.
- Отдельным APK рядом — можно (лицензия не мешает), но не по стилю; запасной вариант.

## Лицензии кандидатов (проверено по GitHub 2026-11-21)

| Проект | Лицензия | Вывод |
|---|---|---|
| fluxroot/pulse (Java, C++; Kotlin/Native «in progress») | MIT | **берём**, переписываем на Kotlin: 0x88, псевдозаконные ходы, оценка «материал + мобильность», альфа-бета, поиск покоя, UCI |

## Сеть

- **FICS (freechess.org:5000)** — основной вариант: гость без регистрации и токена. Проверено 2026-11-21 с хоста: `login: guest` → «Logging you in as "GuestXXXX"; you may use this name to play unrated games», затем MOTD. Протокол — текст по TCP; позиция строкой `<12>` (style 12: 8 рядов, чей ход, рокировки, номера партии, ники, контроль, часы, последний ход). Гость — только безрейтинговые партии. Число игроков онлайн **не измерено**.
- **lichess** — по желанию позже: OAuth2 PKCE, `client_id` — любая строка, регистрация приложения не нужна, scope `board:play`; редирект на `http://localhost:<порт>` может принять сервер из B26. Партии по переписке (1–14 дней) и компьютер lichess (уровни 1–8, `POST /api/challenge/ai`) — только там. Каждый запрос — с `User-Agent`. Анонимного входа в официальном API нет; внутренний протокол сайта не используем.
- Ограничения при любой сети: сон книги (B19) во время партии с часами нужно запрещать; часы на E-Ink обновлять реже раза в секунду; блиц на E-Ink неудобен.

## Размер APK (оценка, не замер)

Релиз 1.0.0: 4 478 840 Б; `classes.dex` 318 КБ при 34 376 строках Kotlin (118 файлов) ≈ 9 Б на строку. Шахматы без натива: ядро 1,5–2,5 тыс. строк, экраны 2–3 тыс., FICS 0,6–1 тыс., lichess 0,8–1,2 тыс. → **+50–80 КБ** (~4,55 МБ). Фигуры — векторные контуры, как `IconSpecs.kt`. Набор задач, если встроим, +40–100 КБ. Точную цифру записать после первого шага (до/после `assembleRelease`).

## Что не проверено

Сила Pulse на 32-битном PX30 (рейтинг, время хода); число живых игроков FICS и наличие там долгих контролей (15+10 и выше); можно ли блиц с людьми через lichess Board API.

## Шаги

1. 25.0 — макеты (вопрос в `DESIGN_QUESTIONS.md`); ядро можно без них.
2. 25.1 — `chess/`: перенос Pulse на Kotlin + FEN + SAN + правила ничьей; perft на хосте (**Opus**, новое ядро).
3. 25.2 — экран доски и игра против компьютера, уровни по глубине/времени с неточностями, сохранение партии (Sonnet, нужны макеты).
4. 25.3 — клиент FICS гостем: сокет, разбор `<12>`, поиск соперника, часы, запрет сна на партию (решение по архитектуре сети — Opus, экран — Sonnet).
5. 25.4 — lichess через браузер, по желанию.
6. Лицензия Pulse (MIT) — в `docs/LICENSES.md` и на B75 при шаге 25.1.

## Решение 2026-11-27: 25.4 (lichess) отменён, п. 25 закрыт

- Требование человека — игра по сети без аккаунта. Спецификация lichess (`api-board-seek.yaml`): Board API требует OAuth2 `board:play`, то есть аккаунт. `POST /api/challenge/open` создаётся без токена (`security: []`), но анонимные игроки играют по ссылке на сайте, а не через API.
- Внутренний протокол сайта не используем (решение 2026-11-21). Анонимная игра с людьми — FICS гостем (25.3), проверена на книге 2026-11-27.
