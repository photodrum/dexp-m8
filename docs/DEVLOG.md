## 2026-11-11 — автор и название из имени файла (EPUB и другие форматы без метаданных)

Замечание пользователя: в B2 первая строка — «Автор. Название», вторая — «Автор неизвестен · EPUB». Причина — не дизайн: метаданные читает только FB2-ядро (`NativeBook.metaFb2`), у остальных форматов автор был `null`, а название — имя файла целиком. На книге: 500 EPUB + 11 FB2, имена вида «Автор. Название.epub».

`Scanner.splitName`: делит базовое имя на автора и название по первому «. »; инициалы («Теренс Х. Уайт. Меч в камне», «Чехов А. Доктор») не считаются концом автора; без «. » — «Автор, Название» при 2–3 словах слева. Не делится (остаётся имя файла): цифры или ЗАГЛАВНЫЕ слева, «Сборник», «Альманах…» не исключены. `sortFromName`: «Имя Фамилия» → «Фамилия Имя» для ключа `author_sort`. Метаданные FB2 приоритетнее имени. Проверка на 511 именах с книги: без автора 3 («А.Н. Толстой. …», «Сборник. …», «ФАТА-МОРГАНА-2. …»). Известное: «Альманах научной фантастики. Выпуск 19» разбирается как автор «Альманах научной фантастики»; «А.Н. Толстой» без пробела не делится.

`LibraryDb.VERSION` 1 → 2: `onUpgrade` обнуляет `mtime`, сканер переразбирает все файлы (статус, прогресс, «добавлена» не меняются). Проверено на книге (APK из Gradle, поставлен поверх): скан «518, новых 0, обновлено 518, ошибок 0, 2835 мс»; B2 — «Джо Аберкромби · EPUB», «Александр Абрамов, Сергей Абрамов · EPUB»; B12 — название и автор раздельно; сортировка по автору верная. Позже, с читалкой (CREngine/MuPDF), метаданные из файла заменят разбор имени.
