# B73 «Словари» — решение «одна секция», экран и дверь с B41 (2026-11-18, Sonnet)

## Решение

Пользователь 2026-11-18 выбрал вариант B из трёх, предложенных в `docs/DESIGN_QUESTIONS.md`:
**одна секция «Словарь» — «Викисловарь · по сети» + «Сервер перевода → MyMemory»**. Офлайн-словари
не делаем совсем (ни загрузки на 58–110 МБ, ни «Добавить из файла… StarDict/DSL»): словарь в R5.2а —
онлайн, сервера словарей у проекта нет, парсера StarDict/DSL в коде нет. Вариант C (выбор второго
языка перевода) отложен: направление по-прежнему угадывается по алфавиту текста.

## Почему не «просто оставить макет»

`design/v5/B73.json` — две секции («УСТАНОВЛЕНЫ» 59,250 и «ДОСТУПНЫ ДЛЯ ЗАГРУЗКИ» 59,650) и пять
строк: Ожегов 58 МБ, Мюллер 110 МБ, Даль 96 МБ, русско-английский 74 МБ, немецко-русский 81 МБ,
«Добавить из файла…». Ни одна строка не переживает отказ от оффлайна — без него остались бы
заголовок «Словари», подзаголовок «2 установлено · 168 МБ» и пустая панель. Поэтому экран собран
из **того же шаблона строки** (`название 42/700` + `описание 32/600 G4` + `разделитель G11`),
но с двумя строками источников.

## Что сделано

- `ui/SetDictScreen.kt` — новый экран по числам B73: шапка `41,113.5 / 176,105 / 176,181`,
  раздел «СЛОВАРЬ» `59,250`, панель `41,298 1321×312`, строки `88,327 / 88,380.5`,
  разделитель `88,451`, вторая строка `88,479 / 88,487 / 88,532.5`.
  Значение второй строки — `kit.valueRow` (34/600 G4, правый край 1267.6), как «Мюллер» и т.п.
- `SCR_SET_DICT = 26` в `EinkActivity`, регистрация в `obtain()`.
- `SetLangScreen` (B41): строка «Словари» теперь **нажимается** и ведёт на B73; значение
  `767.6,1534.5` — «по сети» / «нет сети» по `DictOnline.online()`. Раньше строка рисовалась без
  значения и без перехода (в макете у неё стоит «2 установлено» — эти данные больше не существуют).
- Подзаголовок B73 — «Викисловарь · MyMemory» вместо «2 установлено · 168 МБ».
- Живое на экране только одно: без сети первая строка пишет «Нет сети — словарь не откроется».

## Чего сознательно нет

- **`next` и дверей** — у этих строк в макете стрелки не было, экранов за ними тоже нет.
- **Ключей в `Prefs`** — сервер один и зашит константой `MYMEMORY` в `DictOnline`. Заводить
  настройку без второго значения — мёртвый ключ.
- **Тумблера «Искать без сети»** — без сети искать нечем, строка говорит это текстом.
- **Выбора языка перевода** — это вариант C, отдельный шаг (см. `docs/DESIGN_QUESTIONS.md`).

## Осталось по макету (не блокирует код)

- **B41** — у строки «Словари» в макете значение «2 установлено»; кода такого счёта больше нет,
  просьба поставить «по сети».
- **B73** — секции «Установлены»/«Доступны для загрузки» и пять строк офлайн-словарей в макете
  больше не отражают продукт; оставить одну секцию «СЛОВАРЬ» с двумя строками.
- **B30** — подпись источника «Толковый словарь Ожегова · без сети» в макете против
  «Викисловарь · CC BY-SA` в коде (расхождение было и до этой правки).
- **B75** — строк «Викисловарь» и «MyMemory» в списке лицензий нет (`docs/LICENSES.md` п. 34).
