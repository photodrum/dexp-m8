## Факты E-Ink: объём и радиусы по снимку

> Перенесено из `docs/CONTEXT.md` (2026-11-09). Эти числа новее таблиц выше (п. 2б, шаг 1).

- Объём — ступенчатые слои без размытия (числа сняты со слоёв `design/v5`, шаг 1 п. 2б):
  - выпуклая: все три слоя одного размера `W-4.6 × H-10.1`: тень `G10 +4.6,+10.1` →
    блик `G15 0,0` → поверхность `G14 +2.8,+2.8`;
  - вдавленная: нижний блик `G15` (`W × H`) → внутренняя тень `G10` (`W-2.7 × H-2.8`) → дно
    `+2.7,+5.5` (`W-5.5 × H-8.3`, радиус на 2.74 меньше); дно **G11** на фоне экрана,
    **G12** внутри карточки и в дорожках прогресса;
  - тёмная клавиша: `G8` тень → `G6` блик → `G3` поверхность.
- Радиусы: плитка/панель/поле `51.1875`, карточка B1 `58.5`, главная кнопка `65.8125`,
  гнездо обложки `32.90625`, внутреннее `30.1640625`, большая обложка `18.28125`,
  обложка в строке `10.96875`, батарея `21.9375`, желоб `43.875`, сегмент `36.5625`,
  дорожка B1 `14.625`.

Палитра: Фон сменён G13 → G12 в макете 2026-11-08; в коде фон G12 (`T.BG`) с п. 2б, шаг 1.

## Факты Penpot

> Перенесено из `docs/CONTEXT.md` (2026-11-09).

- **Как пользоваться макетами — `docs/DESIGN_USAGE.md`** (читать перед любым экраном).
- Файл «UI»; рабочая **v5** — 76 бордов 1404×1872 (B1–B76).
  Сетка: шаг по X 1564, ряды Y = 19864 / 22100 / 24300; B47–B76 — с Y = 25005, шаг 2200.
- Имена: `B1 · Главный экран · Пластик · 1404×1872` … `B76 · …`.
- Страница `v5 дизайн-система` — 10 досок спецификации: цвета, типографика, объём,
  иконки, кнопки, поля, карточки, шапки/пагинация, листы/диалоги, сетка и правила E-Ink.
  У каждого компонента подписан борд-источник. Цвета и 17 текстовых стилей лежат
  в библиотеке файла (DEXP M8 / Палитра, DEXP M8 / Manrope|Literata).
- `page.root.children.filter(s => s.type === 'board')` — только борды холста.
  `findShapes({type:'board'})` рекурсивен и даёт все вложенные (209 и т.п.) — **не путать**.
- У `path`-фигуры есть готовое свойство `d` (в координатах страницы) — нормализуем
  в систему иконки вычитанием её `x,y`.
- Иконка в макете — группа из двух слоёв: блик `#FFFFFF` со сдвигом `+3,+3` под контуром.
- `export_shape` для страницы отдаёт PNG 1×1 — бесполезно, экспортировать только борд по id.

## Ключевые факты E-Ink: экран и палитра (из CONTEXT.md)

> Перенесено 2026-11-09. Продолжение — в разделе «Факты E-Ink: объём и радиусы по снимку» выше.
