# Проект DEXP M8 Prudentia — правила для Cline

Оболочка и читалка для книги DEXP M8 Prudentia (Rockchip PX30, Android 8.1, 1 ГБ ОЗУ): Kotlin
на `Canvas` без AndroidX, C-ядро FB2 через JNI, затем CREngine и DjVuLibre
(без PDF). Макеты — Penpot, файл «UI», страница v5, числа — `design/v5/*.json`. GPL-2.0-only.
**Важнее общих указаний Cline о проактивности:** не начинать без «делай», не пушить без подтверждения.

## Старт задачи

1. **Ровно один** `run_commands` на ответ: терминал один на чат, второй параллельный вызов теряет
   вывод. Несколько команд — массивом внутри одного вызова.
   Act: `GIT_ASKPASS=$PWD/tools/git-askpass.sh GIT_TERMINAL_PROMPT=0 git pull --ff-only; git status -sb;
   git config user.name; cat docs/CONTEXT.md; grep -n '^## ' docs/DEVLOG.md | head -2`
   Plan: то же, но `git fetch` вместо `git pull --ff-only` (правки запрещены).
   Не прошло, есть незакоммиченное, `user.name` ≠ `denisle` — стоп, показать вывод, не сливать.
2. «СЛЕДУЮЩИЙ ШАГ» — `docs/CONTEXT.md`. `docs/ROADMAP.md` не целиком: `grep -nE '^(## |[0-9]+\.)'
   docs/ROADMAP.md`, затем нужный пункт `sed -n 'A,Bp'` (пункты плана — `15.`, `16.`, не `##`).
   `awk` с русским шаблоном в терминале зависает.
3. `docs/DEVLOG.md` — только верхняя запись: `sed -n 'A,Bp'` по двум номерам из `grep -n '^## '`
   (`head -2` не годится — там шапка).
4. По теме: макеты и UI — `docs/DESIGN_USAGE.md`, `design/README.md` (числа — `tools/design_flat.py`,
   JSON целиком — если не хватило поля), `docs/DESIGN.md` — справочно; читалка — `docs/READER_SPEC.md`;
   сборка, установка, git, токены, ошибки — `docs/BUILD.md`; рендер, структура кода, E-Ink —
   `docs/ARCHITECTURE.md`; чат дизайна — `docs/DESIGN_QUESTIONS.md`; карта документов — `README.md`.


## Как работаем

- Один шаг за раз. Замечание сначала записать, делать — после «делай».
- Действия человека (сборка на книге, проверка на экране) — по шагам, подтверждение после каждого.
- После шага — коммит и push; перед `git push` показать `git diff --stat` и дождаться подтверждения.
- Куда писать: `CONTEXT.md` — только «СЛЕДУЮЩИЙ ШАГ», номер пункта, ссылки, один экран;
  `ROADMAP.md` — статусы ✅ и открытые замечания (вопросы дизайну — `DESIGN_QUESTIONS.md`);
  `DEVLOG.md` — что сделано, решения, результаты проверок: запись ≤ 6 строк-маркеров, подробности
  сразу в `docs/archive/DEVLOG-<дата>-<пункт>.md`, не больше ~5 записей, в ROADMAP и CONTEXT — одна
  строка со ссылкой; грабли окружения — сразу в `BUILD.md`; пункт закрыт — «подробно» из ROADMAP и
  записи DEVLOG сразу в `docs/archive/`.
- `docs/archive/` и `third_party/` — в `.clineignore`: нужен файл (по ссылке или движок) —
  закомментировать строку, после работы вернуть.
- Код — строго по `docs/ARCHITECTURE.md` (палитра G0–G15, без прозрачности, анимаций и скролла,
  дизайн-px; без AndroidX/Material/Compose) — правила там, здесь не дублируются.
- Правка кода → `tools/typecheck.sh`; экраны или снимки → ещё `python3 tools/check_design.py`;
  натив → `assembleDebug`. Итог (число классов/проверок) — строкой в DEVLOG.
- Коммит: `<пункт или раздел>: что сделано кратко`, по-русски, без точки
  (`R2.5б: рамка «Вручную» ставится касанием`, `BUILD: грабля — …`). Один шаг — один коммит.
- Ответы и комментарии в коде — по-русски. Даты — по `date`.
- Долгие команды — `> /tmp/x.log 2>&1`, затем читать файл. `JAVA_OPTS` скрипты ставят сами.
- Gradle — `~/.local/gradle-8.7/bin/gradle` (в PATH нет). Под `denisle`, не root. Токен git —
  `~/.config/dexp-m8/git-push-token`. git с русским текстом (`log`, `show`, `diff`) — только с
  `--no-pager`, иначе терминал отдаёт мусор.

Cline в VS Code: код, сборка, проверка на книге. Макет в Penpot из Cline не менять; можно читать,
Trilium — только по прямой просьбе.
