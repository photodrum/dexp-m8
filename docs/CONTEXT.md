## Проект в двух словах

Своя оболочка и читалка для DEXP M8 Prudentia (E-Ink 1404×1872, Android 8.1, `armeabi-v7a`,
1 ГБ ОЗУ): Kotlin на `Canvas` без AndroidX, C-ядро FB2 через JNI; читалка — CREngine /
DjVuLibre после оболочки (без PDF). Макеты — Penpot, файл «UI», страница v5; числа берём из `design/v5/*.json`.
Лицензия — GPL-2.0-only.
