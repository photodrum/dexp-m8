# Проект DEXP M8 Prudentia — правила для Cline

Кастомная оболочка и читалка для электронной книги DEXP M8 Prudentia.
Единственный источник правды — этот репозиторий. Заметки, переписка и память могут устареть.

## В начале каждой задачи

1. `git pull --ff-only` — в `main` коммитят и отсюда, и через GitLab из чата дизайна.
   Если pull не проходит — остановись и покажи вывод, ничего не сливай сам.
2. Прочитай `docs/CONTEXT.md` — «СЛЕДУЮЩИЙ ШАГ» (вверху), карта документов и правила.
   Полный план и номер текущего пункта — `docs/ROADMAP.md`.
3. Прочитай последние 2–3 записи `docs/DEVLOG.md`.
4. Остальное — по надобности:
   - UI: `docs/DESIGN_USAGE.md`, `design/README.md`; числа брать из `design/v5/*.json`,
     `docs/DESIGN.md` — только справочно;
   - читалка: `docs/READER_SPEC.md`;
   - окружение, сборка, установка на книгу, git и токены: `docs/BUILD.md`;
   - рендер, структура кода, правила E-Ink: `docs/ARCHITECTURE.md`;
   - план и подробности текущего пункта: `docs/ROADMAP.md`.
5. `git status` — незакоммиченных изменений быть не должно; `git config user.name` — `denisle`.

Если в CONTEXT.md нет ответа — искать в ROADMAP.md, затем в DEVLOG.md. Если и там нет — спросить, не выдумывать.

## Как работаем

- Язык — русский.
- Один шаг за раз. Замечания пользователя сначала записывать, делать — после слова «делай».
- Если действие должен сделать человек (сборка на книге, настройка, проверка на экране) —
  расписать по шагам и ждать подтверждения после каждого.
- После каждого шага обновить `docs/CONTEXT.md` (следующий шаг, номер пункта), `docs/ROADMAP.md`
  (отметки и подробности) и `docs/DEVLOG.md`, закоммитить и запушить.
  `CONTEXT.md` держать в один экран: подробности — в `ROADMAP.md`.
  Перед `git push` показать, что уходит, и дождаться подтверждения.
- Код и скрипты — без воды, строго по ограничениям E-Ink: только палитра G0–G15, без
  прозрачности, размытия, анимаций и скролла; без AndroidX/Material/Compose; дизайн-px, не dp.
- Работаем под `denisle`, не под root. Токен git — `~/.config/dexp-m8/git-push-token`.

## Кто что делает

- **Чат дизайна** (Claude, Penpot): макеты, дизайн-система, снимок `design/v5/*.json`,
  документы по дизайну и ТЗ.
- **Cline в VS Code** (хост tools): код, сборка, проверка на книге.
- Макет в Penpot из Cline не менять. Разрешено только читать: снять снимок ещё не снятого
  экрана через `tools/penpot_dump.js` (см. `design/README.md`) и проверить `tools/check_design.py`.
- Заметки в Trilium менять только по прямой просьбе.
