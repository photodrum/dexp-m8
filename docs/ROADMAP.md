22. **B61: не видно доступных сетей Wi-Fi** (замечание человека 2026-11-18). Список в макете
    есть (четыре строки 66,752.9 и ниже), а в коде его нет: на Android 8.1 `getScanResults()`
    без `ACCESS_COARSE_LOCATION` и включённого определения местоположения возвращает пусто,
    а `connectionInfo.ssid` — `<unknown ssid>`. Проверено на книге: `location_mode = null`,
    `wifi_scan_always_enabled = 0`, права в манифесте нет. **План:** добавить право, просить
    его на шаге (или объяснить, почему без него никак), включить «сканирование Wi-Fi» запросом
    через `Settings.ACTION_LOCATION_SOURCE_SETTINGS`, читать `getScanResults()`, рисовать
    строки по макету (имя 42/700, «Защищена паролем»/«Открытая сеть», `lock` справа), касание
    по сети — подключение: открытая сразу, с паролем — экран B47 (в макете он есть: поле
    пароля 56,1102 и клавиатура 30,1410; своей клавиатуры у нас `ui/Keyboard.kt`).
23. **B63: в строке версии нет автора** (замечание человека 2026-11-18). На B43 строка —
