## 2026-11-11 — замечание 1, проба контраста, чистка EinkActivity (Opus)

- **Замечание 1 (белый кадр после диалога права на холодном старте).** Причина подтверждена по коду: `requestStorage()`

  Проверка на книге: удалить приложение, поставить заново, запустить → в трассе `storage: granted|denied`, затем
  ровно один `eink: clean after dialog`, следа «РАЗРЕШИТЬ» нет.
