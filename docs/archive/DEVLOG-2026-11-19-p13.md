## 2026-11-18 — Низкий заряд B20: сделано, проверено на книге (Opus)

- `core/Power.kt` — заряд и зарядка (липкий `ACTION_BATTERY_CHANGED`), порог экономии из `Settings.Global.low_power_trigger_level` (пусто — 15 %), «примерно N часов чтения» (20 ч на полный заряд), экономия = Wi-Fi и подсветка с возвратом при зарядке.
- `ui/LowBatteryScreen.kt` — B20 по числам макета поверх затемнённого экрана (фильтр `dimmed`, как у шторки B5); `EinkActivity.checkBattery` — один вход, три исхода: зарядка снимает экономию, ≤ 3 % — сохранить страницу, заставка B19 и меню питания, ≤ порога — диалог один раз за разряд (при включённом тумблере B40 экономия включается без диалога).

- Грабли: `dumpsys battery set level` не меняет `status` — при `status: 5` книга считается заряжающейся, нужен `set status 3`.
- Проверки: `typecheck` 266/0, `check_design` 331/249/0, `assembleDebug` ок (5,76 МБ). Подробно — `docs/archive/DEVLOG-2026-11-18-b20.md`.
