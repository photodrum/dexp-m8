## СЛЕДУЮЩИЙ ШАГ

- **R4.2 — B27 «Закладки и заметки»** (Sonnet). Данные готовы: `LibraryDb.marks(bookId)` отдаёт
  `Mark(id, pos, page, chapter, text, created)`, `markCount(bookId)` — число для подписи вкладки.
  Переход по закладке — `Engine.gotoPos(pos)` (позиция движка, а не номер страницы). Макет
  `design/v5/B27.json`: шапка как у B10, вкладки «Оглавление / Закладки · N / Заметки · M»,
  панель с строками «Стр. N · Глава», дата, цитата, пагинация «1 / 1». Заметки — пусто до B50–B52.
- **Дальше в R4 — нужен Opus (натив):** **B28 «Поиск по книге»** и **B50–B52 «Выделение, цитаты,
  заметки»**. В `.so` нет `search`, `wordAt`, `rects`, `text` — надо писать в `cre_session.cpp`
  (+ JNI в `reader_jni.cpp`, обёртки в `Engine.kt`), затем экраны.
- **Зоны касаний B39** — по-прежнему ждут ответа дизайну (`docs/DESIGN_QUESTIONS.md`, верхний):
  «Классическая» и «Две половины» после вычета центральной колонки дают одну схему.
