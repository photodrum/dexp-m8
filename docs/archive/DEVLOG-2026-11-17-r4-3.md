### Решения, которые стоили времени

1. **Подсветку движку не отдаём.** `LVDocView::selectRange/selectWords` рисует свою заливку
   цветом из настроек, а по макету B50 плашка — G12 с точными отступами. Поэтому выделение
   живёт в `g_sel` (свой `ldomXRange`), страница рисуется как обычно, а плашки оболочка кладёт
   сама по `dexp_reader_selection_rects`. Это же в ROADMAP п. 17 («плашкой G12 по рамкам слов
   от движка, не `getRange`»).
2. **Время жизни `g_sel`.** Диапазон держит `ldomXPointer` в DOM вида. Если не уронить его
   до `delete g_view`, следующий `createXPointer` читает освобождённое дерево — падение.
   Потому `sel_clear()` стоит в `drop_document()` **до** удаления вида и в `relayout()`.
   По той же причине `g_search` бросается в `relayout`: xpointer старого DOM после новой
   разметки указывает в другое место (R1.2, DEVLOG 2026-11-13).
3. **Координаты.** `getSegmentRects` отдаёт координаты документа, окно — через
   `docToWindowPoint`. Верхняя точка обычным вызовом, нижняя — с `isRectBottom=true`: низ
   строки совпадает с верхом следующей, без флага отрезок уехал бы на другую страницу.
4. **Поиск.** `findText(pattern, true, false, 0, 0, ranges, 500, 0, -1, false, flags)`.
   `minY=maxY=0` = весь документ (движок сам чинит границы в пустом месте). `maxHeight=0`
   критично: cr3qt зовёт с высотой страницы и нашёл бы только текущую. Флаги —
   `MATCH_ACROSS_TEXT_NODES | COLLAPSE_CONSECUTIVE_SPACES`: без них слово, разбитое курсивом
   на два узла, не находится.
5. **Запятая в слове.** `getWordRange` режет только по пробелам, `wordAt` возвращал
   «стриженым,». Добавлена `is_word_punct`. Коды Unicode записаны **числами**: кириллические
   литералы (`'—'`, `'«'`) в `switch` дают на ARM `character too large for enclosing character
   literal type` — сборка падает 16 ошибками.

## Проверка на книге

Книга: `/sdcard/Books/r43.fb2` (копия «Белой гвардии», 1,7 МБ, 420 страниц). Запуск:
`adb shell am start -n ru.ogrpfsense.dexpm8/.ui.EinkActivity --es reader /sdcard/Books/r43.fb2`
— самотест `EngineSelfTest`, шаг `findStep(buf)`.

```
selftest: find слово='hommenote' из=C'est un tres brave hommenote 49. Да ты сам его знаешь.
selftest: find 'hommenote' n=1 код 1 1067ms
selftest: find[0] стр.453 hommenote
selftest: find[0] gotoPos → стр.453 СТРАНИЦА СОВПАЛА
selftest: wordAt(702,800) попыток=0 слово='стриженым'
selftest: text выделения='стриженым' pos=true…true
selftest: rects выделения=1
selftest: extend(+1)=1 'стриженым, поделом' rects=1
selftest: rects saved=1
selftest: clear → выделение='нет' поиск остался=1
selftest: после setFont выделение='нет' поиск=0
```

Что подтверждается:

- поиск находит вхождение по всей книге (стр. 453 — не та, где стоял движок), 1 с на 420 страниц;
- `gotoPos` по позиции найденного встаёт ровно на ту страницу, что назвал поиск;
- слово под точкой — без пунктуации, xpointer начала и конца получены;
- прямоугольники дают 1 отрезок на однострочное слово и на сохранённый диапазон — то, что нужно
  B50 (плашка G12) и B52 (подчёркивание G3 / заливка G13);
- смена кегля бросает и выделение, и найденное: устаревшие xpointer не живут.

`tools/typecheck.sh` — 208 классов, 0 ошибок. `assembleDebug` — успешно.

## Грабли окружения (в `docs/BUILD.md`)

1. **Правка C++ не попадает в APK.** Gradle пишет `buildCMakeDebug[armeabi-v7a]` и
   `BUILD SUCCESSFUL in 1s`, `.so` в `app/build/intermediates/cxx/…/obj` свежий, но
   `mergeDebugNativeLibs` остаётся `UP-TO-DATE` — в APK уезжает старый файл, на книге ведёт
   себя старый код. Лечение: `rm -rf app/build/intermediates/merged_native_libs
   app/build/intermediates/stripped_native_libs`, затем `assembleDebug`. Признак —
   `find app/build -name 'libdexp_cre.so' -printf '%TH:%TM %p\n'`: даты `merged`/`stripped`
   старее, чем `cxx`.
2. **SIGBUS на самотесте.** Первые `page 0`/`page 1` прошли, дальше `Fatal signal 7 (SIGBUS),
   code 1 (BUS_ADRALN)` в `dexp-engine` — битый кэш разметки
   `cache/cre/<книга>.<хеш>.0.cr3` (запись 2026-11-15). Удалять **после** `am force-stop`:
   живая Activity перезаписывает кэш, и удаление не помогает. `pm clear` не использовать —
   сотрёт базу.
