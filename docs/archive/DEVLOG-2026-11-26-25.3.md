# 25.3а — FICS гостем: протокол, клиент, партия по сети, запрет сна (2026-11-26, Opus)

Сложная часть 25.3: ядро сети и архитектура. Экраны B85–B87 — 25.3б (Sonnet), план ниже.

## Что сделано

- `chess/Style12.kt` — строка `<12>`: доска → FEN, чей ход, рокировки, номер партии, имена,
  отношение (1 наш ход, −1 их, 0 смотрим, 2 разбор), контроль, часы в мс, номер хода, последний
  ход подробно → UCI (`lastUci`: «P/e2-e4», «o-o», «P/a7-a8=Q»), «часы идут».
- `chess/FicsEvent.kt` — события (вход, позиция, начало и конец партии, seek, ничья, возврат
  хода, незаконный ход, закрытие) и `FicsEnd` (мат, сдача, флаг, ничья, отмена, отключение).
- `chess/Fics.kt` — `FicsLines` (байты → строки: «\n\r», IAC, «fics% », склейка чанков),
  разбор строк, команды (`moveCommand`, `seekCommand`, `setup`).
- `chess/FicsClient.kt` — сокет и два потока («fics-read», «fics-write»), вход гостем, пинг
  раз в 60 с, тайм-аут чтения 150 с (мёртвый Wi-Fi виден за ~2,5 мин), `close` = «quit».
- `chess/NetGame.kt` — своя `Game` в согласии с сервером: свой ход сразу, ход соперника
  проигрывается по `lastUci`, отказ сервера и возврат — откат, иначе пересборка из FEN; часы
  (`clockMs`, `running`, `clockText` «11:58»). Время — монотонное, его даёт вызывающий.
- `ui/ChessNet.kt` — одно соединение на процесс (как `ChessSession`, без `Context`): состояния
  IDLE → CONNECTING → READY ⇄ SEEKING → PLAYING → ENDED, OFFLINE (B87); события в UI-поток через
  `Handler(main)`, событие помечено своим клиентом (хвост старого после `leave` не мешает).
- `EinkActivity.holdAwake(who, on)` — `FLAG_KEEP_SCREEN_ON` у окна и без заставки B19, пока
  `ChessNet` ищет или играет (`onAwake` ставится в onCreate, снимается в onDestroy только своё).
- Тесты: `tools/chess_fics_test.kt` (из `chess_test`, **+62 → 265 / 0**, строки — дословно с
  сервера); `tools/fics_live.kt` — два гостя через `FicsClient` + `NetGame` на живом сервере
  (**23 / 0**). `typecheck` 446 классов, новых предупреждений нет; `check_design` 395 / 0;
  `assembleDebug` ок. **На книге не проверено**, экранов нет.

## Протокол — проверено на freechess.org 2026-11-26 (два гостя с хоста)

- Вход: «login: » (без \n) → `guest` → «Press return to enter the server as "GuestXXXX":» →
  пустая строка → `FF FC 01` (IAC WONT ECHO) и «**** Starting FICS session as GuestXXXX(U) ****».
  Гостя сразу глушат в каналах (adminBOT) — играть это не мешает.
- Строки — «\n\r», приглашение «fics% » в начале следующей строки, чанк TCP режется посреди строки.
- Ход: `e2e4`; рокировка — `o-o` или ходом короля `e1g1` (оба приняты); превращение —
  `a7a8=q` (**`a7a8q` — «Command not found»**). Незаконный — «Illegal move (e2e5).» и прежняя
  позиция `<12>` (часы уже с поправкой).
- Начало: «Creating: …» и «{Game N (A vs. B) Creating unrated standard match.}», затем `<12>`.
  Часы стоят до первого хода каждой стороны (поле «часы идут» = 0).
- Конец: «{Game N (A vs. B) <текст>} <итог>»: «Game drawn by mutual agreement» 1/2-1/2,
  «X resigns», «X checkmated», «X forfeits on time» (autoflag сервера, часы −1535 мс),
  «Game aborted on move 1» *, «X forfeits by disconnection» — **сразу, доигрывания у гостей нет**.
- Ничья: «X offers you a draw.» → `draw` = согласие, `decline` → «X declines the draw request.».
  Возврат: «X would like to take back 1 half move(s).» → отказываем сами.
- `set open 0` — чужой `match` отвергается («… is not open to match requests»), `seek` при этом
  выставляется («Your seek has been posted with index 22. (9–10 player(s) saw the seek.)»).
- `iset ms 1` — часы в мс; `observe` чужих партий — тот же `<12>`, отношение 0.

## Решения

1. Сервер главный: его позиция всегда побеждает; ход на своей доске — сразу (кадр E-Ink не ждёт сети).
2. Выход посреди партии = поражение: экран (25.3б) спрашивает, как B84.
3. Возврат хода и отмену партии соперника не принимаем — автоматический `decline`.
4. Сон: `FLAG_KEEP_SCREEN_ON` (без `WakeLock` и прав), B19 не планируется; «Сон» на B5 работает.
5. Связь пропала после конца партии — не B87, а тихо IDLE: следующий поиск соединится заново.
6. Без timeseal: на 15 + 10 и 10 + 5 задержка сети (~130 мс, по `<12>`) не съедает время.

## 25.3б — экраны (Sonnet), по макетам B85–B87б

- B77: строка «По сети» (подзаголовок FICS) → B85; при `ChessNet.state` PLAYING — «Вернуться к партии».
- B85: сегменты `Fics.CONTROLS`, «Искать соперника» → `ChessNet.seek(min, inc, VERSION_NAME)`.
- B85а: диалог поверх B85, «0:42» — от `ChessNet.seekSince` (раз в секунду только этот текст),
  «Отмена» → `cancelSeek()`. PLAYING → B86.
- B86: доска `ChessBoard` по `ChessNet.net!!.game`, касание → `ChessNet.move(m)`; полосы — имя и
  часы (`clockText(clockMs(цвет, now()))`, «идут» — тёмная плашка B86, «стоят» — светлая);
  перерисовка часов — не чаще раза в секунду и только их рамка; B86а — мало времени.
- B87 — OFFLINE (`error`), «Повторить» / «Настройки Wi-Fi» (как B57); B87а — ENDED с
  `FicsEnd.DISCONNECT`; B87б — `drawOffered`: «Принять» → `draw()`, «Отклонить» → `declineDraw()`.
- `ChessNet.onChange` — ставить при показе экрана, снимать при уходе; выход из сети — `leave()`.
