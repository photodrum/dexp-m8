# 25.2 — экраны шахмат и игра с компьютером (2026-11-26, Sonnet)

Один шаг в коде, не проверен на книге: проверка — по `docs/CHECKS.md`, «Шахматы на книге».

## Что сделано

- **Вход:** синтетическая плитка «Шахматы» в B6 (как «Файлы»: `AppEntry("Шахматы", "", "chess", "chess")`,
  по алфавиту, без «…», не входит в «N установлено»). Касание → B77.
- **Экраны:** `ChessMenuScreen` (B77/B77а), `ChessNewScreen` (B78), `ChessScreen` (B79/B79а/B79б),
  `ChessMovesScreen` (B81); листы и диалоги — `ChessSheets` (B80 превращение, B82 меню партии) и
  `ChessDialogs` (B83 конец / B83а ничья, B84 «Сдаться?»). Рисование доски — `ChessBoard`.
  `SCR_CHESS_MENU/NEW/CHESS/MOVES` = 42…45 в `EinkActivity`.
- **Игра:** `ChessPlay` (касания, поиск в потоке, отмена, ничья, сдача); `ChessSession` — общая
  партия для B79 и B81 (только числа и `Game`, без `Context`). Поиск идёт на `Position.copy()`
  с `Level.of(уровень)`; устаревший результат отбрасывается по счётчику поколений.
- **Сохранение:** `Prefs.chessSave` = `GameSave.encode` (`1|уровень|цвет|конец|время|e2e4 e7e5 …`),
  пишется после каждого полухода и при сдаче/ничьей; `Prefs.chessLevel`/`chessColor` — последний
  выбор на B78. B77: «Продолжить партию» — первой строкой, если сохранение есть.
- **Ядро:** `chess/RuSan.kt` (Кр Ф Л С К, решение 2026-11-26), `chess/Saved.kt` (`GameSave`).
  `tools/chess_test.kt` — 25 новых проверок (203 / 0).
- **Инструмент:** `tools/design_flat.py` — `B79а` больше не превращается в `B79А` (файл не находился).

## Решения и отступления от макета

1. **Нет «По сети»** на B77 (25.3) и подзаголовок «С компьютером»; панель короче на шаг строки.
2. **Нет «ЧАСЫ»** на B78 (на B79 нет места под часы) — вопрос в `DESIGN_QUESTIONS.md`.
3. **Взятие** — кольцо G5 8 px вместо точки (в макете состояния нет) — вопрос там же.
4. **Предложить ничью:** право на ничью (3 повтора, 50 ходов) — принимается сразу; иначе поиск
   глубиной 3 до 2 с: принимает при оценке для игрока ≥ +0,3 пешки, после 30-го хода — и при
   равенстве. Отказ — «Компьютер отказался» на полосе компьютера до следующего хода.
5. **Отмена хода:** свой ход и ответ компьютера; пока компьютер думает — только свой; без своих
   ходов кнопка серая (G6) и не нажимается. Партия окончена — отмены нет (диалог B83 модальный).
6. **B83:** закрывается только кнопками; «Назад» = «В меню» (стирает сохранение). «Смотреть
   ходы» → B81, возврат показывает диалог снова.
7. **Выход из партии** («Назад» на B79, «Меню» → «Закрыть») оставляет сохранение; при возврате
   компьютер, если его очередь, думает заново.
8. **Доска при игре чёрными** повёрнута сама (B79б); «Перевернуть доску» — вручную. Полосы стоят
   на местах: сверху всегда компьютер.
9. `check_icons`: имена фигур записаны буквально в `ChessBoard.NAMES` — скрипт ищет их по тексту
   (теперь «иконок, которых нет в коде» — 0).

## Грабли

- Редактор: вставка по `insert_line` в файл **без завершающего перевода строки** попадает перед
  последней строкой — закрывающая `}` оказалась в конце файла (ChessPlay, ChessBoard, ChessScreen,
  chess_test). Файл из нескольких вставок — сначала создавать целиком, а при нужде сверять
  `wc -l` с последней строкой по `read_files`.
- Лимит редактора на один вызов — ~6000 символов: большие экраны писать частями.
